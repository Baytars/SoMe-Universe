## Purpose & Doctrine

The **Cradle Protocol** governs the tactical execution of human target acquisition and substitution operations within Project MARY. Named for the dual meaning of "cradle" — the place where something begins and the container in which something is held — the protocol describes the complete cycle from abduction to operational insertion.

**Core Doctrine**: *"The target is both the key and the lock. We take both."*

**Operational Sequence**: 
```
ABDUCTION → IMPRISONMENT → INSERTION → VERIFICATION
```

**Secondary Windows** (Moderate Success Rate):

| Window | Duration | Risk Factor |
|--------|----------|------------|
| Social Events | Variable | Witness density |
| Family Gatherings | Variable | Relationship familiarity |
| Vacations | Variable | Location unpredictability |

### Abduction Methods

**Method A: Pharmaceutical Insertion** (Preferred)

```
TECHNIQUE: Target unknowingly consumes fast-acting sedative
├──载体: Food, drink, medication
├──药剂: Ultra-short-acting benzodiazepine + opioid combination
├──生效: 3-5 minutes post-consumption
├──持续: 4-6 hours (sufficient for transport)
└──恢复: Gradual awakening with retrograde amnesia
```

**Method B: Physical Intervention** (Secondary)

```
TECHNIQUE: Direct application by trained extraction team
├──手段: Taser → Restraint → Rapid transport
├──声响: Minimal (suppressed equipment)
├──时间: 2-5 minutes total operation
└──风险: Higher physical evidence (bruising, etc.)
```

**Method C: Administrative Manipulation** (Tertiary)

```
TECHNIQUE: Coercion through fabricated legal/medical authority
├──载体: Fake arrest warrant / Medical emergency summons
├──配合: Target voluntarily accompanies
├──优势: No physical force required
└──限制: Requires extensive forged documentation
```

## Phase 4: Verification

### Operative Integration Period

**Duration**: 96 hours (4 days) following insertion

**Verification Milestones**:

| Milestone | Time | Verification Method |
|-----------|------|---------------------|
| Initial Contact | T+0 | Routine interactions with household/staff |
| Professional Resumption | T+24 | Return to work, scheduled meetings |
| Social Contact | T+48 | Family/friend interactions |
| Security Check | T+72 | Identity verification at checkpoints |
| Comprehensive Review | T+96 | Full behavioral assessment |

### Success Criteria

| Criterion | Threshold | Measurement |
|-----------|-----------|-------------|
| Identity Acceptance | 100% | Zero identification alerts |
| Professional Competence | ≥85% | Work performance within normal variance |
| Behavioral Accuracy | ≥90% | No anomalies reported by close contacts |
| Security Clearance | Maintained | Access credentials functional |
| Cover Story Durability | 100% | Absence explanation accepted |

### Failure Response Protocol

**Detection at Any Stage**:

```
ABORT CRITERIA:
├── Operative requests extraction
├── Behavioral accuracy drops below threshold
├── Identity compromise detected
└── Target proximity risk exceeds tolerance

ABORT PROCEDURE:
1. Operative executes emergency withdrawal
2. Cover story deployed ("abducted, escaped")
3. Medical intervention to explain anomalies
4. Reconditioning period for operative
5. Original target disposition (see below)
```

**Original Target Disposition** (If Operative Fails):

| Option | Condition | Execution |
|--------|-----------|-----------|
| Continued Imprisonment | Operative replacement planned | Maintain indefinitely |
| Memory Wipe & Release | Exposure risk acceptable | Neural conditioning, identity erasure |
| Elimination | Exposure risk unacceptable | Documented accident/disappearance |
