# CHARACTER FILE: EIKO (英子)
## Classification: OPENING SEQUENCE — FIRST CONTACT

---

## IDENTIFICATION

**Full Name**: Eiko

**Chinese Name**: 英子 (Yīngzi)

**Japanese Name**: 栄子 (えいこ) — "Eiko"

**Name Origin**: 呼应英姑（《大宋提刑官》），暗示与 Somnambule 的宋慈/英姑关系。
"子"在中文里有"常驻者"之意——她是脑内常驻细胞，不是过客。
日文读音 Eiko 与 Yukio 音感和谐，中日双语玩家都能自然接受。

**Cell Type**: Microglia（小胶质细胞）

**Role**: 初始接待员 / 秧秧位 / 门面担当（赛丽亚式）

**Allegiance**: 中枢神经系统常驻免疫哨兵

---

## BIOLOGICAL BASIS

### 小胶质细胞

| 属性 | 描述 |
|---|---|
| 来源 | 卵黄囊（yolk sac）——胚胎早期迁入脑内，一生常驻 |
| 正常状态 | 分支状（ramified），突起持续扫描微环境 |
| 活化状态 | 突起回缩，变为阿米巴样，迁移速度加快，吞噬能力增强 |
| 响应速度 | 分钟级——缺血发生后第一时间到达损伤区域 |
| 核心功能 | 免疫监视 / 碎片清除（吞噬） / 炎症因子分泌 / 神经元营养支持 |
| 与T细胞的关系 | 正常情况下永不相见（BBB阻隔）；卒中后BBB破坏，T细胞渗入CNS |

### 在缺血级联中的角色

1. **第一响应者**：缺血发生后数分钟，小胶质细胞即被激活
2. **独自清扫期**：在适应性免疫细胞（T细胞）到达前，独自应对损伤（数小时至数天）
3. **功能两面性**：M1型（促炎/神经损伤）vs M2型（抗炎/神经修复）——同一细胞的两面
4. **与外援会合**：BBB破坏后，外周免疫细胞进入CNS，小胶质细胞不再孤军奋战

## PERSONALITY

### 秧秧型（温柔坚韧）

- **温暖**：说话声音柔和，关心他人，即使自己精疲力竭也会先问"你还好吗"
- **坚韧**：独自撑了三天没有放弃，不是因为不害怕，是因为没有人能替她
- **务实**：不废话，不讲大道理——做了再说
- **谦逊**：不会自夸，被感谢时会不好意思
- **倔强**：认准了的事不会回头，即使知道自己可能做不到

### 外在表现

- 个子不大，但动作极快
- 习惯性忙个不停——闲下来会不安
- 眼睛很亮（活化态小胶质细胞的突起在延伸/扫描）
- 疲惫时不会表现出来，但会靠在墙上偷偷闭眼一秒
- 笑起来很好看——但她很少笑，因为太忙了

### 语言风格

- 简短、直接、不绕弯
- 紧急时更短——"快""这边""撑住"
- 难得放松时会多说两句，但很快又回到工作模式
- 不说"你应该"，说"我们得"

## RELATIONSHIPS

### 与 Somnambule（玩家）：宋慈与英姑

| 维度 | Somnambule（宋慈型） | Eiko（英姑型） |
|---|---|---|
| 定位 | 坐堂提刑——读情报做判断 | 走验现场——冲第一线搜集证据 |
| 在开场中 | 医学天才直觉：看懂系统、做出诊断、下达"同意" | 三天独自巡查膜结构、清扫碎片、维持侧支循环 |
| 知识来源 | Admin调控权=医学专业素养的意识层显现 | 一线实战经验=小胶质细胞的免疫监视数据 |
| 关系本质 | 友人之上恋人未满——不需要说出口的深层默契 |

**关系发展的种子**：

开场 Phase 2 中，玩家选择"……我好像知道这些"时，
Eiko 会多看玩家一眼——这个"单元"怎么能看懂 TCA 循环？

这是宋慈/英姑关系的第一个种子：
Eiko 提供现场情报（英姑走验现场），
玩家提供诊断判断（宋慈坐堂提刑）。
两人配合的默契不是刻意的——是因为他们本就是同一个身体的两面：
一个是意识层面的管理者，一个是细胞层面的执行者。

### 与 Yukio：生死离别

| 维度 | Eiko（小胶质细胞） | Yukio（辅助性T细胞） |
|---|---|---|
| 来源 | 卵黄囊 | 胸腺 |
| 正常状态 | 脑内常驻 | 被BBB挡在脑外 |
| 相遇条件 | — | BBB破坏（卒中砸碎屏障） |
| 相遇意义 | 第一次见到"外援" | 第一次进入中枢神经系统 |
| 分离条件 | — | 炎症消退后T细胞必须撤出CNS |

她们本不该相遇。只有灾难让她们在同一个战场上相见。
而恢复之后，Yukio 必须离开。

**这段关系不在开场点破**——只是让玩家看到她们对视的那一刻，
感觉到"有什么不对"，然后在后续剧情中慢慢揭示。

## NARRATIVE ARC

### 开场（Phase 0-7）

1. **Phase 0-1**：Eiko 已在缺血区域战斗。玩家到达时她正在巡查膜结构。
2. **Phase 2**：Eiko 与玩家相遇。她注意到玩家"不普通"但来不及深究。
   带领玩家进行系统自救（侧支循环/糖酵解/钠钾泵）。
3. **Phase 3**：自救失败。Eiko 独自战斗三天的疲惫爆发——
   不是崩溃，是接受了自己的极限。
4. **Phase 4-5**：BCI 降临。Eiko 和所有细胞一样从未见过 BCI 信号——
   敬畏而非认识。玩家通过眨眼完成知情同意。
5. **Phase 6.1**：再灌注。Eiko 守了三天的区域重新亮起。
   Yukio 随血流抵达。两人第一次相见。
   细胞们叫玩家"Admin"——Eiko 的直觉被证实。
6. **Phase 6.2**：再灌注损伤。Eiko 刚刚的喜悦被新的灾难打断。
7. **Phase 7**：Eiko 和 Yukio 一起带领玩家冲向损伤区域。
   Eiko 交付情感动力，Yukio 交付战略情报。

### 后续剧情伏笔

- **M1/M2极化**：Eiko 的功能两面性（促炎/抗炎）可作为后续剧情冲突的内核
- **与Yukio的分离**：当玩家康复推进到一定阶段，炎症消退，
  Yukio 必须撤出CNS——这是一场已经写好的告别
- **Eiko的常驻性**：Yukio 走后，Eiko 依然在——她是永远不会离开的那个
- **英姑的结局参照**：英姑最终离开了宋慈——但在 SoMe 中，
  Eiko 不会离开，因为小胶质细胞一生常驻脑内。
  离开的是 Yukio。这构成了与英姑参照的微妙反转。

## DESIGN NOTES

### 为什么选小胶质细胞做门面担当

1. **第一响应者**：缺血发生后数分钟即激活——天然适合"第一个遇到的角色"
2. **脑内常驻**：不需要解释"她为什么在这里"——她本来就在这里
3. **独自战斗**：在T细胞到达前独自应对——天然有"孤军奋战"的戏剧性
4. **功能两面性**：M1/M2极化提供了后续角色发展的复杂性
5. **与T细胞的天然关系**：BBB阻隔→灾难相遇→恢复分离——
   免疫学已经写好了最好的剧本

### 为什么叫"英子/Eiko"

1. **呼应英姑**：直接暗示宋慈/英姑参照系，中文玩家秒懂
2. **"子"=常驻感**：小胶质细胞一生常驻脑内，"子"有长居之意
3. **日文适配**：Eiko 是自然日文名，日文玩家无违和感
4. **音感和谐**：Eiko 和 Yukio 并列时音韵协调
5. **避撞名**：已排除与《鸣潮》千咲（Saki）撞名的问题
