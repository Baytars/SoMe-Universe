## 2. 角色外观设计

### 2.1 整体风格

**碳基生物朋克——不是机甲，不是纯生物，是"活着的终端"。**

净蚀使徒是银白重型机甲战士；守域使徒是完全相反的路线——**小、快、安静，但你能感觉到她一直在看**。她的设计语言是"持续运行的守望协议"：即使站在原地不动，她身上的元素也在微微运转，像一台从不休眠的监控终端。但当她从监视态切换到战斗态时，背甲突起重组为一柄比她还高的补体巨剪——**安静的小个子扛起荒谬的大武器**，这种反差就是她的视觉记忆点。

### 2.2 三态外观变换

小胶质细胞的核心形态特征是**分支状（ramified）↔ 阿米巴样（ameboid）**的转换。这在游戏中表现为 Eiko 的三态外观：

**【监视态 · 分支状】**

- 身形纤细，身高偏矮（"个子不大"——角色档案）
- 头发末端分裂成数条细丝，持续微微摆动，像在扫描空气中的信号
- 细丝在暗处会发出极淡的青绿色荧光——模拟 Iba1 染色特征
- 眼神沉静、警觉，像永远在观察
- 动作特征：移动时几乎无声，习惯性环顾四周

**【战斗态 · 阿米巴样】**

- 发丝收束成利刃状，身体略微膨胀
- 原本纤细的轮廓变得紧凑有力——"突起回缩，体态致密化"
- 动作从"扫描"变为"猎杀"
- 配色饱和度提升，青绿色变得更深

**【M1 极化态 · 促炎】**

- 发丝末端燃烧成橙红色焰心，像氧化反应的可视化
- 皮肤浮现红色纹路——炎症因子（TNF-α / IL-1β / IL-6）释放的视觉信号
- 眼神变冷——不是冷酷，是"目标锁定"
- 左手的"吞噬"器官涡旋加速，发出低频嗡鸣

**【M2 极化态 · 抗炎】**

- 发丝末端泛出柔和的蓝白色光晕
- 红色纹路消退，取而代之的是淡蓝色修复纹路——IL-10 / TGF-β 信号
- 眼神变暖——"我在这里，没事了"
- 右手的"探针"延伸出更多分支，像在编织修复网络

### 2.3 标志性元素

| 部位 | 设计 | 生物学映射 |
|---|---|---|
| **★身份标志·补体巨剪** | 一柄比 Eiko 本人还高的巨型双刃剪刀。刃身由补体蛋白晶体凝聚而成，半透明带暗金荧光纹路。平时拆解收纳为背甲上的分支突起（ramified态），战斗时重组为巨剪（ameboid态） | 补体级联（C1q标记→C3转化→CR3识别→MAC穿孔）。剪=补体激活的"标记-清除"过程可视化 |
| **左手** | 可变形的吞噬器官——平时是手掌，战斗时张开成涡旋状裂口 | 吞噬作用（phagocytosis） |
| **胸口** | 微微搏动的暗金光点 | 常驻协议——小胶质细胞一生驻留CNS |
| **发丝** | 末端分叉，持续运动 | 分支状形态——免疫监视的物理基础 |
| **脚底** | 光脚——没有鞋。脚印会在地面留下极淡的荧光痕迹，3秒后消失 | 小胶质细胞在脑实质中的迁移轨迹 |

### 2.3.1 补体巨剪 · 身份标志武器设计

> **设计原则**：武器不是道具，是身份标志。参考鸣潮千咲——没了巨剪她只是个平平无奇的水手服女学生，拿上巨剪才是"那个用剪刀的"。Eiko 同理：没了补体巨剪她只是个安静的小个子守望者，扛上巨剪才是"守域使徒"。

**视觉规格**：
- 剪刀全长约 Eiko 身高的 1.5 倍，闭合时如一柄巨型阔刃剑，展开时双刃如铡刀
- 刃身：补体蛋白晶体（C3转化酶可视化），半透明，内部可见流动的暗金色信号纹路
- 关节轴心：搏动的暗金光点——与胸口光点同源，象征补体级联的启动核心
- 携带方式：ramified态时拆解为背甲分支突起（与发丝末端的细丝同构）；ameboid态时突起回缩重组，巨剪从背甲"生长"出来，Eiko 单手或双手握持

**战斗语义**：
- **剪切动作 = 补体标记清除**：一剪下去，C3b 标记沿刃口接触面蔓延，目标被"标记"后突触连接断裂
- **闭合剪 = 精确切除**：单条冗余突触的手术刀式清除（发育期修剪 / M2态修复）
- **展开劈 = 大范围清除**（M1态）：ROS风暴叠加补体级联，巨剪展开横扫，刃口释放氧化损伤
- **剪断音效**：不是金属"咔嚓"——是生物组织断裂的湿润脆响 + 补体激活的高频嗡鸣叠加

**两态武器形态**：
| 形态 | 巨剪状态 | 战斗风格 |
|---|---|---|
| 监视态（ramified） | 拆解为背甲突起，不可使用 | 侦察/标记，用发丝细丝轻触目标完成C1q标记 |
| 战斗态（ameboid） | 重组为完整巨剪，可挥砍/剪切 | 近战斩击 + 补体标记 + 吞噬收尾 |
| M1极化态 | 巨剪刃口燃起橙红焰心，展开模式可用 | 暴力横扫，ROS + 补体双系统输出 |
| M2极化态 | 巨剪缩小为手术剪尺寸，闭合模式 | 精确修剪，清除冗余但不伤及正常组织 |

### 2.5 动态效果

- **待机动画**：发丝末端持续摆动（扫描循环），偶尔快速转向某个方向又收回——检测到信号但又判断为无威胁
- **移动动画**：极低姿态滑行，几乎没有脚步声。移动路径不是直线而是锯齿形——模拟小胶质细胞在脑实质中的非定向迁移
- **极化切换动画**：身体短暂僵直0.5秒，胸口光点剧烈搏动，发丝颜色从一端向另一端渐变扩散，伴随一声低沉的"咔"——像开关被扳动
- **被击败动画**：发丝全部断裂飘散，身体缩小蜷缩，胸口光点变暗——但没有熄灭。3秒后从原地重新凝聚（CNS 内自增殖）

## 3. 角色背景故事

### 3.1 世界观定位

> *在碳基赛博空间中，小胶质细胞是 CNS 领域的常驻守护进程。她们不需要从外部调入——她们从胚胎期就在这里，是这个领域的原始居民。当灾难降临，所有外部支援都被 BBB（血脑屏障）挡在门外时，只有她们还在。*

### 3.2 角色故事

**【暗夜孤守】**

缺血发生时，没有警报。

不是没有警报系统——是信号传导链已经断了。TCA 循环停转，α-KG 耗竭，整个区域的代谢网络像断电的服务器一样一盏盏熄灭。突触连接中断（连接断开）的信号在微环境中扩散，像一栋大楼里逐层熄灭的灯。

Eiko 是第一个到的。

不是因为她的速度最快——虽然确实很快。是因为她**本来就在这里**。她的分支状突起覆盖着这片区域的每一个角落，24小时不间断地扫描微环境。当第一个突触终端（终端）发出异常信号时，她用了不到一分钟就完成了从监视态到战斗态的转换。

然后她发现自己面对的是一个她从未见过的敌人。

不是病原体。不是外源入侵。是**系统本身在崩溃**——能量供给中断，离子平衡瓦解，细胞开始死亡。这不是她熟悉的免疫战场。这是一场系统级灾难。

她开始做她唯一能做的事：清扫。吞噬死亡细胞的碎片，释放营养因子维持残存神经元的代谢，用突起包裹受伤的突触终端防止二次损伤。一个人。

六小时后，她以为会有支援。没有。BBB 还完整，外周免疫细胞被挡在外面。

十二小时后，她开始感到疲惫。小胶质细胞不擅长长时间高负荷作战——她们是哨兵，不是正规军。

二十四小时后，她的分支状突起已经全部回缩，变成了完全的阿米巴样战斗形态。她在损伤核心区和半暗带之间来回奔波，像一个急诊科医生在两个抢救室之间跑。

四十八小时。她已经不记得自己吞噬了多少碎片。M1 和 M2 之间的极化切换越来越频繁——在损伤核心区切 M1 清除坏死组织，在半暗带切 M2 保护残存神经元。每次切换都在消耗她的调控权（权限），而调控权的来源——α-KG——正在枯竭。

七十二小时。

她靠在一段断裂的突触上，闭了一秒眼。

不是放弃。是太累了。

然后她感觉到一个信号。不是来自微环境的。是来自**更高层**的——一种她从未感知过的、微弱但确实存在的意识波动。

*「……我好像知道这些。」*

她睁开眼。

*这个"单元"怎么能看懂 TCA 循环？*

---

**【与净蚀使徒的本质区别】**

净蚀使徒（中性粒细胞）的故事是**壮烈牺牲**——6小时寿命，一命换六敌，NETs 展开后即为终局。

守域使徒（小胶质细胞）的故事是**孤独坚守**——不是一次性燃烧，而是持续的、看不到尽头的、没有支援的防守。她的悲剧性不来自死亡（她不会死，她能自增殖），而来自**孤独**和**两面性**。

她是同一个身体里既是刀刃又是绷带的存在。M1 时她在破坏——清除坏死组织时也会误伤存活的神经元。M2 时她在修复——但修复需要资源，而资源正在枯竭。

她每一次极化切换都在问自己：*现在是该破坏还是该修复？*

而她没有参考答案。因为没有人在。

直到 Somnambule 醒来。

### 3.3 考据彩蛋

| 彩蛋 | 真实医学背景 |
|---|---|
| **"第一响应者"** | 小胶质细胞在缺血后数分钟即被激活，是脑内最早响应损伤的细胞 |
| **"独自撑了三天"** | 脑缺血后，适应性免疫细胞（T细胞）在48-72小时才开始渗入CNS。在此之前，小胶质细胞独自应对损伤 |
| **"卵黄囊来源"** | 小胶质细胞起源于卵黄囊（yolk sac）巨噬细胞，在胚胎早期迁入CNS，与外周巨噬细胞来源不同。这使她成为CNS的"原住民" |
| **"自增殖"** | 小胶质细胞在CNS内可自我更新维持群体数量，不依赖骨髓补充（与外周免疫细胞不同） |
| **"分支状→阿米巴样"** | 静息态小胶质细胞呈分支状（ramified），活化后突起回缩变为阿米巴样（ameboid）——这是小胶质细胞最经典的形态学特征 |
| **"M1/M2 极化"** | 小胶质细胞的功能两面性：M1（经典激活/促炎/神经损伤）vs M2（替代激活/抗炎/神经修复）。同一细胞的两面，不是两个亚型 |
| **"突触修剪"** | 发育期小胶质细胞通过吞噬修剪多余的突触，塑造神经网络连接——这成为她的"地形改造"技能来源 |
| **暗金配色** | 致敬 Pío del Río-Hortega（1919），他用碳酸银染色法首次鉴定了小胶质细胞，被称为"小胶质细胞之父" |
| **Iba1 青绿色** | Iba1（离子钙结合接头分子1）是小胶质细胞最常用的免疫组化标记物，染色呈棕褐色/暗青色 |
| **"不穿鞋"** | 小胶质细胞直接在脑实质中迁移，没有血管通道——她"踩"在组织上移动 |

## 4. 战斗设计

### 4.1 核心机制：极化切换（Polarization Shift）

**这是守域使徒的灵魂机制。**

小胶质细胞的 M1/M2 极化不是一个简单的"攻击/防御"切换——它是一个**带代价的战略选择**：

| 极化态 | 定位 | 优势 | 代价 |
|---|---|---|---|
| **M1 促炎** | 攻击/清除 | 高伤害、强吞噬、快速清除坏死组织 | **误伤友军**：M1 状态下 Eiko 的攻击会对相邻友方神经元造成溅射伤害。炎症因子不分敌我 |
| **M2 抗炎** | 修复/维持 | 治疗、清除有害代谢物、保护神经元 | **输出极低**：M2 状态下 Eiko 几乎没有攻击力，且移动速度降低 |
| **监视态** | 侦察/部署 | 高视野、可发现隐形单位、部署"突触哨" | **无法攻击**：监视态下攻击力为零，被攻击时受到额外伤害 |

**极化切换规则：**

1. 切换不消耗行动次数，但消耗 **α-KG**（代谢资源）
2. 同一回合内最多切换 1 次（防止反复横跳）
3. 切换有 **1回合冷却**（极化锁定）
4. M1→M2 切换时，Eiko 当前回合剩余行动力减半（"炎症消退需要时间"）
5. M2→M1 切换时，Eiko 立即获得额外行动力（"炎症激活是瞬时的"——这与生物学一致：促炎反应快，抗炎消退慢）

**设计意图：**

M1 的"误伤友军"机制是核心张力。玩家会**想用 M1**（因为伤害高、清场快），但必须承担附带损伤。这模拟了真实的神经炎症困境：**小胶质细胞的促炎反应在清除病原/碎片的同时，也会通过炎症因子损伤健康神经元。**

> *在 SoMe 中，不存在"无代价的攻击"。每一次 M1 极化都是一次「知情同意」——玩家必须知道附带损伤会发生，然后选择承担。*

### 4.2 技能列表

#### 被动技能

**【常驻协议】Passive · CNS Resident**

- Eiko 在 CNS 地图上不会被永久击杀。被击败后，3 回合内在最近的"突触节点"重生，生命值恢复 50%
- 但每次重生后，极化锁定 2 回合（只能使用监视态），模拟小胶质细胞增殖再分化的时间
- **地图限制**：仅在 CNS 地图生效。非 CNS 地图无法部署 Eiko

**【第一响应】Passive · First Responder**

- 战斗开始时，Eiko 自动获得第一个行动回合（在其他所有单位之前）
- 如果开场时 Eiko 处于监视态，她的首次扫描范围扩大 50%
- **叙事整合**：这对应缺血后数分钟内小胶质细胞即被激活的生物学事实


## 8. 设计总结

### 8.1 角色核心矛盾

**守域使徒的核心矛盾是"双面性"——她是同一个身体里的刀刃和绷带。**

净蚀使徒的矛盾是"牺牲"（一命换六敌，死亡即终局）——一次性、壮烈、决绝。
守域使徒的矛盾是"选择"（每时每刻都在M1和M2之间做选择，每个选择都有代价）——持续性、煎熬、无法逃避。

她不能像净蚀使徒那样"燃烧殆尽"——因为她是常驻者。她不能死，不能走，不能放弃。
她只能一遍又一遍地在破坏和修复之间切换，每一次切换都在问自己：

> *现在是该破坏，还是该修复？*

而正确的答案，取决于战场态势——这是玩家必须做出的判断。

### 8.2 与净蚀使徒的设计代差

| 维度 | 净蚀使徒（细胞狂热时代） | 守域使徒（SoMe时代） |
|---|---|---|
| 设计哲学 | 中二+考据的反差萌 | 碳基生物朋克——生物学本身即是叙事 |
| 战斗深度 | 固定技能+数值成长 | 三态切换+资源管理+地形改造 |
| 代价机制 | 死亡（一次性） | 误伤友军（持续性战略博弈） |
| 世界观 | 免疫王国（平行幻想） | 碳基赛博空间（生物真实=计算真实） |
| 叙事深度 | 背景故事（文本层） | 贯穿主线的角色弧线（系统层） |
| 术语体系 | 直接用医学术语 | 碳基术语优先 + 硅基术语作玩家透镜 |
| 角色关系 | 羁绊对话（好感度） | 宋慈/英姑 + 生死离别（叙事驱动） |

### 8.3 在 SoMe 三大玩法中的角色

| 玩法维度 | Eiko 的角色 |
|---|---|
| **免疫战场（SRPG）** | 核心单位——极化切换型战士，三态切换+地形改造 |
| **解剖开放世界** | 引导NPC——CNS区域的常驻向导，提供区域情报和任务 |
| **医学史穿越** | 历史章节NPC——在 del Río-Hortega 章节（1919）中登场，见证小胶质细胞的发现 |
