## 3. Canonical Nation-File Template

Every file follows this structure so the revision pass can fill gaps uniformly:

1. **Front matter** — `layout`, `title`, `status: DRAFT`, `continent`
2. **Designation** — official name, demonym, name etymology (anchored to an anatomical double meaning)
3. **Geography & Territory** — continent, key anatomical features and their institutions
4. **Government & Politics** — regime type, sovereign office, decision bodies
5. **Economy & Strategic Contribution** — what the state pools into the AAA
6. **Medical-Doctrinal Posture** — prevention vs. deterrence lean, academy links
7. **Military** — forces and AAA integration
8. **History** — accession context; later eras
9. **Relations** — within the Accord, toward Umin
10. **Open Items** — explicit `[TBD]` list for hy3
11. **Cross-references**

**Hard rules for fillers:**
- Real-world country names never enter these files (Inazuma principle).
- Carbon-based terminology only; silicon terms forbidden except the single exception "Admin."
- One term, one meaning — do not reuse an established SoMe term for a new sense.
- Anchor every new institution to a real anatomical/physiological feature before inventing.
- Do not resolve an open canon conflict inside a nation file; flag it in §4 below.

## 4. Open Conflicts Requiring Owner Decision

These block full canonization and should be settled before/while hy3 revises:

1. **"Thoracic" vs. "Thoracica".** Roster uses the adjective "Thoracic" as a continent name; canon uses **Thoracica**. Recommendation: standardize on **Thoracica** and correct the roster. *(Default applied in all nation files.)*
2. **"Kingdom of Thoracia" vs. Aukin.** Both sit on Thoracica. Recommendation: treat **Thoracica as the continent**, hosting both the theocratic Empire of Aukin and the secular Kingdom of Thoracia — distinct polities, like the multiple states of Lumbar. Confirm.
3. **Cervical continent is undefined.** Its institutions, climate and polities exist only as names. Cervia/Medulla/Dura/Nerve need real anatomical anchors (cervical marrow, carotid/aortic bodies, cervical plexus, larynx/thyroid proximity). Owner direction wanted on scope.
4. **Geopolitical nations vs. the functional "Ten Banners."** The IF project (story.ni, "The Ten Banners") partitions the world by **physiological system** (vascular, mineral, thyroid, stromal, lung, neuroendocrine…); these 14 states partition by **geography**. The relationship (does each nation align to a Banner? are Banners trans-national functional orders?) is undefined and must not be guessed.
5. **Roster cross-references are stale.** [Athena_Aegis_Accord.md](../Organizations/Athena_Aegis_Accord.md) §CROSS-REFERENCES points to `../SoMe_Factions/`, `../SoMe_Characters/`, `../SoMe_Scripts/`, which do not exist; real dirs are `Factions/`, `Characters/`, `Scripts/`. Named targets (Duchy_of_Alopes.md, Anstar_Empire.md, Tiberson file) were also missing — this nation set supplies Alopes/Anstar; a dedicated Tiberson file remains [TBD].
6. **Tiberson tenure.** Founder Emperor Tiberson convenes the 2312 summit and the same name is current Supreme Commander in 2352 (40 years). Acceptable under cellular time-scale, or a dynastic name — please confirm so history is written consistently.
