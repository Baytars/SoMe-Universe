## 0. 写在前面：为什么是「化合物娘化」而不是「角色娘化」？

SoMe 是一艘以神经元重编程为终极隐喻的医学游戏。我们需要一种**玩家能在不查资料的情况下也能感受到「化学魅力」**的视觉系统。

传统娘化卡牌（gacha）系统的角色是人类角色（英灵/历史人物），对医学专业玩家门槛太高——他们必须先记住人物历史背景，才能对角色产生情感。

**SoMe 的革命性创新：直接娘化化合物本身。**

四大好处：

1. **科学中性** — 碳骨架+官能团是天然的设计语言，无版权问题
2. **临床刚需** — 神经内科医生日常接触的化合物（tPA、胰岛素、阿司匹林、依达拉奉等），用娘化形式让医学生「想了解化合物」时，自然被角色设计倒推着去查分子机制
3. **收集与合成统一** — 化学合成需要原料+反应条件+产物——这正是娘化卡牌的养成过程。收集卡牌=收集化合物
4. **AI 友好** — 化合物的结构特征是确定的、可参数化的，AI 生图时比"历史人物"更可控

**甜蜜点：合成=收集。** 玩家不会觉得自己在学化学，他们会觉得自己在攒老婆/老公。

## 1. 设计哲学：守恒量与涌现量

### 1.1 三大守恒量（不可妥协）

无论任何化合物娘化，**必须保留**：

- **公主切发型**（前短后长，锁骨下方齐刘海的视觉符号）
- **白皙瓷肌**（避开所有"古铜""小麦""晒伤"色调）
- **淡腮红**（含蓄内敛，避开大浓妆/烟熏妆）

> 这三条守恒量是「Alopesian 美学」的核心——参考 `SoMe_Design/Style_Design/Alopesian_Couture_Meta_Rule.md`

### 1.2 三大涌现量（自由设计）

每个化合物娘化可以自由创造的：

- **头发颜色** — 映射化学家族色系
- **服装与配饰** — 映射分子骨架与官能团
- **姿态与表情** — 映射药理学/临床情境

### 1.3 元规则

**「用最少的硬约束，激发最大的涌现」**

三大守恒量是「最少的硬约束」，3 条规则下，4 个范例就涌现出完全不同的视觉风格：

- 糖类 → 治愈系
- 抗生素 → 守护系
- 激素 → 战斗系
- 止痛药 → 温柔护士系

**化学反应类型映射战斗风格**——这是 SoMe 化学战斗系统的核心隐喻。

## 2. 通用视觉语法（6 条核心规则）

| 化合物结构特征 | 视觉对应 | 范例 |
|---|---|---|
| **官能团**（-OH, -COOH, -NH2） | 配饰（手环、发饰、项链） | OH → 白色珍珠手链；COOH → 绿色环扣 |
| **碳骨架**（链/环/稠环） | 服装廓形（连衣裙/胸甲/披风） | 苯环 → 六边形胸甲；链状 → 飘逸长裙 |
| **手性**（D/L, R/S） | 瞳色（异色瞳/左蓝右金） | D-葡萄糖 → 左金右蓝瞳 |
| **共轭体系**（π 键） | 披风/发带（延伸视觉） | 苯环 → 半透明暗红披风 |
| **极性**（亲水/疏水） | 服装材质（丝绸/皮革） | 亲水 → 丝绸；疏水 → 哑光皮 |
| **活性位点**（酶切位点） | 武器形态（对应药理作用） | 蛋白酶 → 大剑；受体激动剂 → 双刃 |

## 3. 化学家族色系（10 大类）

| 家族 | 主色 | 辅色 | 范例化合物 |
|---|---|---|---|
| **糖类**（碳水） | 樱花粉 | 浅黄 | 葡萄糖、果糖、海藻糖 |
| **脂质** | 鹅黄 | 米白 | 胆固醇、磷脂酰胆碱 |
| **蛋白质/氨基酸** | 雾蓝 | 米色 | 甘氨酸、酪氨酸、色氨酸 |
| **核酸** | 紫色 | 银白 | 腺嘌呤、鸟嘌呤、胞嘧啶 |
| **维生素** | 鹅黄 | 翠绿 | 维生素 C、B 族 |
| **激素** | 暗红 | 蓝 | 肾上腺素、胰岛素、甲状腺素 |
| **抗生素** | 金色 | 蓝灰 | 青霉素、头孢、阿莫西林 |
| **解热镇痛** | 暗红 | 绿 | 阿司匹林、布洛芬、对乙酰氨基酚 |
| **无机盐/金属离子** | 银白 | 冰蓝 | Na⁺、Ca²⁺、K⁺、Mg²⁺ |
| **气体信使** | 浅粉 | 蓝白 | NO、CO、H₂S |

## 4. 四大基础角色范例

### 4.1 葡萄糖娘化（糖类·治愈系）

**化学原型**：D-葡萄糖，C₆H₁₂O₆，己醛糖，5 个 -OH，1 个 -CHO（半缩醛形式）

**视觉设计**：

- **发型**：樱花粉公主切，发梢渐变浅黄
- **服装**：6 瓣花瓣裙（6 个花瓣对应 6 碳环），白色丝绸质感
- **配饰**：
  - 5 个 OH 基团 → 5 颗白色珍珠手链
  - CHO 半缩醛 → 精致小王冠
  - 手性 D 型 → 左金右蓝异色瞳
- **姿态**：双手捧心，温柔治愈微笑
- **职业暗示**：内科治疗师，稳定血糖、补充能量

**slogan**：「六瓣花开，能量自来」

**战斗定位**：辅助 · 治疗 · 能量回复

---

### 4.2 阿司匹林娘化（解热镇痛·护士系）

**化学原型**：乙酰水杨酸，C₉H₈O₄，苯环 + 乙酰基（CH₃COO-） + 羧基（-COOH）

**视觉设计**：

- **发型**：暗红 + 森林绿双色挑染公主切（乙酰基红 + 水杨酸绿）
- **服装**：
  - 苯环 → 暗红六边形胸甲
  - 乙酰基吊坠（CH₃COO-）从胸前垂下
  - 绿色 COOH 腰带系腰
  - 整体：白大褂内搭 + 护士短裙
- **配饰**：听诊器（致敬 Laennec 1816 听诊器发明） + 阿司匹林药瓶形状耳环
- **姿态**：手持温度计，温柔专业
- **职业暗示**：止痛护士、退烧专家

**slogan**：「百年不退，止痛常在」

**战斗定位**：辅助 · 解除控制 · 减伤

---

### 4.3 青霉素娘化（抗生素·守护系）

**化学原型**：盘尼西林，β-内酰胺环（4 元环） + 噻唑烷环（5 元环）融合

**视觉设计**：

- **发型**：金 + 蓝灰色挑染公主切（β-内酰胺金 + 噻唑烷蓝灰）
- **服装**：
  - 4+5 元环融合王冠（双环契合）
  - 深蓝色抗菌战裙
  - 白十字图案守护披风
- **配饰**：1928 Fleming 培养皿形状护身符
- **武器**：长剑，刃部为青霉素破坏细菌细胞壁的"裂解"效果
- **姿态**：守护姿态，剑指前方
- **职业暗示**：感染科守护骑士

**slogan**：「裂解细胞壁，守护无菌境」

**战斗定位**：坦克 · 解除 debuff · 反伤

---

### 4.4 肾上腺素娘化（激素·战斗系）

**化学原型**：Adrenaline，C₉H₁₃NO₃，儿茶酚环（苯环 + 2 个 -OH） + 侧链（-CHOH-CH₂-NHCH₃）

**视觉设计**：

- **发型**：黑红色公主切，儿茶酚胺战斗感
- **服装**：
  - 儿茶酚环暗红胸甲（带蓝色 OH 边）
  - 应急战术紧身衣 + 战术腰带
  - 战立姿态带蓝色光效（战斗状态发光）
- **配饰**：
  - 侧链 NHCH₃ → 银质手环
  - 高跟战靴（"应急启动"速度感）
- **武器**：肾上腺素注射器形双刃短剑
- **姿态**：战斗姿态，眼神凌厉
- **职业暗示**：急救科战斗员

**slogan**：「心跳加速，战斗启动」

**战斗定位**：输出 · 急速 · 暴击

## 5. Twine 0.1 第一个娘化对象：tPA

**化学原型**：组织型纤溶酶原激活剂，5 结构域：

| 结构域 | 功能 | 装备映射 |
|---|---|---|
| **Finger** | 纤维蛋白结合 | 手枪套（远程精准） |
| **EGF** | 表皮生长因子样 | 银护肩（守护光环） |
| **Kringle 1** | 纤维蛋白结合 | 金胸甲（蛋糕卷状盾形） |
| **Kringle 2** | 受体结合 | 流苏腰裙（第二层守护） |
| **Serine Protease** | 丝氨酸蛋白酶催化切割 | 月刃大剑（丝氨酸切割，催化裂解） |

**视觉设计**：

- **发型**：白金色公主切（Serine Protease 神性）
- **服装**：白月十字军修女服（带铅灰色边） + 5 件装备全副武装
- **配饰**：月牙刃 + 圣十字项链 + 白月徽章
- **武器**：月刃大剑 + 银手枪
- **姿态**：白月十字军圣骑士，庄严守护
- **阵营**：**Divine Intermediaries（神之中介者）** —— SoMe 第三阵营，6/17 设计升级新增

**slogan**：「白月圣裁，溶栓复生」

**战斗定位**：终极守护 · 解控 · 复活

**临床情境关联**：

- **缺血性脑卒中** — tPA 4.5 小时时间窗内溶栓
- **心肌梗死** — ST 段抬高型心梗溶栓
- **肺栓塞** — 大面积肺栓塞溶栓

**Twine 0.1 副本设计**：5 分钟临床情境 + 5 装备合成小游戏 + 4.5 小时时间窗紧迫感

## 6. 制作工艺与扩展性

### 6.1 AI 生图流程

1. **化合物分析**：确定化学家族 + 关键结构特征（官能团/骨架/手性）
2. **设计草案**：根据 §2 通用语法 + §3 家族色系起草视觉元素
3. **提示词工程**：固定守恒量（公主切+白皙瓷肌+淡腮红）+ 可变特征（化学结构）
4. **AI 生图**：每次生成 4-8 张，从中筛选最佳
5. **人类 review**：人工检查三大守恒量是否守住
6. **风格锚定**：保留 prompt 模板，确保后续角色风格统一

### 6.2 风格锚定（Prompt 模板）

```
游戏角色立绘风格，
{守恒量：白皙瓷肌，淡腮红，公主切发型，}
{家族色系头色，}
{化合物廓形：碳骨架 → 服装，}
{官能团 → 配饰，}
{手性 → 异色瞳，}
{活性位点 → 武器，}
{姿态与表情，}
写实精致风格，{场景/背景}，高质量
```

### 6.3 后续扩展方向

| 波次 | 时点 | 角色 | 关联系统 |
|---|---|---|---|
| **第一波** | Twine 0.1，2026 Q3 | **tPA**（神经内科主角） | 缺血性卒中溶栓 |
| **第二波** | Twine 0.2，2026 Q4 | 阿司匹林、肾上腺素 | 解热镇痛 + 急救 |
| **第三波** | Godot 1.0，2027 Q1 | 葡萄糖、青霉素、胰岛素 | 生化 + 感染科 |
| **第四波** | Godot 2.0，2027 Q2-Q3 | 神经递质矩阵（多巴胺/血清素/乙酰胆碱/谷氨酸/GABA） | 神经科核心 |

每个化合物的娘化角色都将被收录到「SoMe 化合物娘化图鉴」，作为游戏内收集系统 + 医学教育参考双重资产。
