## 0. 设计哲学

> **生物法则 = 物理法则。属性不是策划拍脑袋填的数字，是生物化学常数的游戏化映射。**

三条铁律：
1. **数值锚定真实生物**——所有属性的基础比例来自真实生物化学参数，经对数压缩后入游戏
2. **双层命名**——每个属性有碳基名（NPC说的）和玩家透镜（UI显示的），CS术语是玩家解读透镜不是NPC母语
3. **暗度陈仓**——玩家不需要知道这些数值背后有免疫学道理，但打多了会自己发现规律

## 1. 核心属性体系

### 1.1 属性总览

SoMe属性体系由 **7项核心属性 + 3项SoMe特有属性 + 派生属性 + 类型标签** 构成。

> **v1.0 修订说明**：原提案8核心属性中ATK与DEF合并为单一Eh轴，核心属性从8项减为7项。

| 类别 | 数量 | 说明 |
|---|---|---|
| 核心属性 | 7项 | 所有单位共有，玩家面板直接可见 |
| SoMe特有属性 | 3项 | 参考游戏完全没有的SoMe差异化维度 |
| 派生属性 | 4项 | 由核心属性计算，不单独培养，不直接显示 |
| 类型标签 | 4项 | 非数值，类似舰R的"射程"等定性属性 |

## 2. 核心机制一：氧化还原势（Eh）轴

> **设计来源**：Senpai R1化学视角洞察——生物的"攻击力"和"防御力"本质是"键能"和氧化/还原能力。

### 2.1 统一原理

ATK和DEF不是两个独立属性，而是**同一氧化还原轴的两个方向**：

```
         氧化端（高Eh）  ←———Eh轴———→  还原端（低Eh）
         ═══════════════════════════════════════════
         ATK强                        DEF强
         夺取电子                      提供电子
         打断化学键                    维持键稳定
         释放能量                      缓冲氧化冲击
         攻击性强                      偏保护
```

**生物化学基础**：
- **氧化（ATK方向）**：强氧化剂夺取目标分子的电子，打断化学键，释放能量 → 对外杀伤
- **还原（DEF方向）**：强还原剂提供电子，维持自身化学键稳定，缓冲氧化冲击 → 对内保护
- 二者在同一轴上，一个细胞不可能同时最大化两者（热力学约束）

### 2.2 ATK和DEF的Eh函数

```
ATK = f(Eh, 极化系数)  →  Eh越高、极化系数越偏M1，ATK越高
DEF = g(Eh, 极化系数)  →  Eh越低、极化系数越偏M2，DEF越高
```

### 2.3 极化类型在Eh轴上的位置

| 极化态 | Eh位置 | ATK | DEF | 免疫学对应 |
|---|---|---|---|---|
| **M1 促炎** | 高Eh端 | 高 | 低 | ROS爆发/促炎因子分泌/吞噬增强 |
| **M2 抗炎** | 低Eh端 | 低 | 高 | 精氨酸酶/IL-10/TGF-β/组织修复 |
| **监视态** | 中性 | 零 | 中 | 分支状突起扫描/低代谢/免疫监视 |

### 2.4 氧化自伤机制

> **派生属性**：氧化自伤 = ATK × (1 - 极化系数)

M1态下，Eiko的强氧化攻击不分敌我——炎症因子对相邻友方神经元造成溅射伤害。

- **M1态**：极化系数=0.85，自伤比例=15%
- **M2态**：极化系数=1.0，自伤比例=0%
- **监视态**：ATK=0，自伤=0

> *这不是bug，是feature。真实的神经炎症困境：小胶质细胞的促炎反应在清除病原/碎片的同时，也会通过炎症因子损伤健康神经元。*

### 2.5 NO双性例外

一氧化氮（NO）是Eh轴上的特殊存在——它**同时具有攻击和防御双重性**：
- **低浓度NO**：信号分子，防御/调节功能（血管舒张、神经传递）
- **高浓度NO**：细胞毒性，攻击功能（iNOS大量产生NO杀病原体）
- 可同时高ATK高DEF，但代价是**自身氧化应激**（NO与超氧反应生成过氧亚硝基ONOO⁻，损伤自身）

**游戏化处理**：NO型角色的自伤不来自极化（M1/M2都有），而是来自**NO浓度过高本身**——这是一个独立于极化轴的自伤来源。

## 3. 核心机制二：HP三维分解

> **设计来源**：Senpai R3洞察——HP"生存力"太抽象，需要拆开。

### 3.1 三维定义

HP不是单一数值，而是**三种不同"耐久"的加权合成**：

| 维度 | 碳基含义 | 生物学锚点 | 承受的伤害类型 | 游戏意义 |
|---|---|---|---|---|
| **体量** | 生物物理质量 | 细胞体积/生物量/物理尺寸 | 吞噬、物理破坏 | 决定"能不能被一口吃掉" |
| **分子稳定性** | 键能/结构复杂度 | 肽聚糖厚度、二硫键密度、荚膜多糖聚合度 | 氧化攻击（ROS打断化学键） | 与Eh轴直接挂钩：高键能=难被氧化打断 |
| **信息冗余** | 基因组缓冲 | 内含子比例/多倍体/基因重复/修复通路完整性 | DNA损伤（ROS致突变、UV嘧啶二聚体） | 决定"挨几次突变才死" |

### 3.2 HP合成公式

```
HP = 体量 × w₁ + 分子稳定性 × w₂ + 信息冗余 × w₃

其中 w₁ + w₂ + w₃ = 1
```

三个子值不直接显示在面板上（避免认知过载），合成后的HP是**固定值**——算完不变。

> **v1.0 修订说明（R4）**：HP保持稳定固定值，不做动态变化。动态修饰全部移至ATK侧。原因：HP动态变化是设计陷阱——玩家无法预测"几回合打死"，破坏SRPG核心体验。

### 3.3 三维作为目标属性标签

三维的真正作用不是改变HP本身，而是作为**目标的属性标签**，决定承受不同攻击类型时的有效耐久：

- 一个革兰阳性细菌面板HP=10000
- 面对吞噬攻击时，有效HP可能=8000（体量中等，吞噬效率尚可）
- 面对ROS时，有效HP=15000（厚肽聚糖层抗氧化，分子稳定性高）
- 面对DNA损伤时，有效HP=6000（原核基因组冗余低，信息冗余低）

> 玩家看到的还是一个HP条，但打不同敌人时"怎么打才疼"不一样——这正是免疫学里**效应机制匹配**的核心思想。

### 3.4 三维天然解释免疫效应匹配

```
病毒: 体量极低 + 信息冗余极低（基因组小，几个突变就废）
 → 不需要"打"，需要"认"（抗体中和/TCR识别）
 → 高亲和精度克之

细菌: 体量中等 + 分子稳定性看革兰染色（G+厚壁 vs G-薄壁）
 → 需要氧化爆发打断细胞壁化学键
 → 高杀伤活性克之，但G+的分子稳定性更高，需要更强的氧化攻击

寄生虫: 体量极高（比免疫细胞大几个数量级）
 → 吞噬不可能、氧化攻击杯水车薪
 → 必须用IgE介导嗜酸性粒细胞脱颗粒——本质是"投掷炸弹"而非"近身肉搏"
 → 需要完全不同的攻击模式
```

**这不是我们设计的克制关系，这是免疫学事实。** 把它做进游戏，玩家自己会发现"大怪不能硬吞，得用炸弹"。

## 4. 核心机制三：ATK目标类型修饰表

> **设计来源**：Senpai R4纠正——动态属性放在ATK侧，通过针对不同种类目标的攻击加成buff修饰实现。

### 4.1 修饰系数表

攻击类型（行）× 目标类型（列）的修饰系数：

| 攻击类型 | vs 病毒 | vs G+细菌 | vs G-细菌 | vs 寄生虫 |
|---|---|---|---|---|
| **吞噬** | 1.0 | 1.0 | 1.2 | 0.05 |
| **ROS氧化爆发** | 0.8 | 0.6 | 1.5 | 0.3 |
| **DNA损伤** | 1.5 | 0.8 | 0.8 | 0.5 |
| **IgE脱颗粒** | 0 | 0 | 0 | 2.0 |

### 4.2 每条规则的免疫学道理

| 格子 | 修饰值 | 免疫学依据 |
|---|---|---|
| 吞噬 vs 病毒 | 1.0 | 吞噬可清除游离病毒颗粒，但效率一般（病毒太小，且胞内复制） |
| 吞噬 vs G+ | 1.0 | 标准吞噬效率，G+细菌可被有效吞噬 |
| 吞噬 vs G- | 1.2 | G-外膜更易被吞噬识别（LPS是强调理素靶点），效率略高 |
| 吞噬 vs 寄生虫 | 0.05 | 寄生虫体积远大于免疫细胞，吞噬几乎不可能——"你吃不了比你大100倍的东西" |
| ROS vs 病毒 | 0.8 | ROS对胞内病毒效果有限，病毒藏在不同区室 |
| ROS vs G+ | 0.6 | G+厚肽聚糖层抗氧化能力强，需要更强氧化 |
| ROS vs G- | 1.5 | G-外膜含脂质A/LPS，对氧化攻击高度敏感——ROS是杀G-的利器 |
| ROS vs 寄生虫 | 0.3 | 大型寄生虫有抗氧化酶系统（过氧化氢酶/谷胱甘肽系统），ROS杯水车薪 |
| DNA损伤 vs 病毒 | 1.5 | 病毒基因组小、冗余极低，几个DNA损伤就废——核酸类似物是经典抗病毒策略 |
| DNA损伤 vs G+ | 0.8 | G+有DNA修复系统，但不算强大 |
| DNA损伤 vs G- | 0.8 | 类似G+，有一定修复能力 |
| DNA损伤 vs 寄生虫 | 0.5 | 大型寄生虫基因组冗余高、修复系统复杂，DNA损伤效率低 |
| IgE vs 病毒 | 0 | IgE通路不针对病毒——零 |
| IgE vs G+ | 0 | IgE通路不针对细菌——零 |
| IgE vs G- | 0 | IgE通路不针对细菌——零 |
| IgE vs 寄生虫 | 2.0 | IgE+嗜酸性粒细胞脱颗粒是抗寄生虫的核心机制——投掷炸弹式的远程攻击 |

### 4.3 最终伤害公式

```
最终伤害 = 基础ATK × Eh极化系数 × 目标类型修饰系数 × 暴击修正

其中：
  基础ATK = 角色面板攻击力（由Eh值和等级决定）
  Eh极化系数 = M1: 1.8 / 监视态: 0 / M2: 0.4（Eiko示例）
  目标类型修饰系数 = 上表中对应格子的值
  暴击修正 = 亲和精度判定暴击时 × 效应放大倍率
```

### 4.4 设计效果

1. **玩家自然学到免疫学**：打寄生虫发现吞噬没用→被迫换IgE型角色→自己发现"免疫系统对不同敌人用不同武器"
2. **角色有定位但不是硬克制**：Eiko的吞噬对寄生虫几乎无效（0.05），但她切换M1后ROS对G-细菌极强（1.5×1.8=2.7倍）——角色不是"全能"也不是"只能打一种"
3. **HP不变化但有效HP概念自然涌现**：玩家打G+细菌用ROS感觉"肉"，打G-用ROS感觉"脆"——这不是G+的HP变了，是分子稳定性高导致ROS效率低

## 5. 核心机制四：缺血-再灌注三相战场环境

> **设计来源**：Senpai R2纠正——主Agent此前错误声称"缺氧区偏还原态→攻击力衰减"暗示还原态=安全。Senpai用依达拉奉适应症纠正：还原态是"装填好的弹药"，再灌注是扣扳机。

### 5.1 三相定义

| 相位 | 微环境状态 | 氧化还原特征 | 免疫单位状态 | 游戏机制 |
|---|---|---|---|---|
| **缺血期** | 缺氧/能量衰竭 | 偏还原（NADH堆积） | 活性降低但蓄能 | 所有单位ATK↓，DEF↑（还原态偏保护），代谢容量消耗加速不回复 |
| **再灌注期** | 复氧/ROS风暴 | 剧烈氧化（超氧爆发） | 所有单位ATK暴涨，含友军误伤 | 所有单位ATK×1.5，氧化自伤×2，M1极化自动触发概率提升 |
| **稳定期** | 恢复正常 | 回归中性 | M2主导修复 | 恢复正常数值，M2态治疗效果+30% |

### 5.2 临床准确表述

> **关键纠正**：缺血期偏还原态 ≠ 安全状态。
>
> 缺血期是**病理蓄能状态**——NADH堆积（还原当量无法通过电子传递链氧化），ATP耗竭，离子泵失效。这不是"还原=防御强=安全"，而是"弹药装填但枪卡住了"。
>
> 再灌注期才是ROS风暴的真正来源：当血流恢复、氧气重新供应时，堆积的NADH在复氧瞬间被氧化，产生大量超氧阴离子（O₂⁻）。这是从"还原蓄势"到"氧化爆发"的相位跳变。
>
> **依达拉奉右莰醇**——自由基清除剂——正是作用于再灌注期，清除复氧瞬间产生的ROS，而非作用于缺血期。

### 5.3 战场道具：依达拉奉

| 属性 | 值 |
|---|---|
| **名称** | 依达拉奉（碳基名）/ 自由基清除剂（玩家透镜） |
| **类型** | 战场道具（消耗品） |
| **效果** | 使用后2回合内，再灌注期的"ATK暴涨"和"氧化自伤×2"效果被抑制。友军和敌军的ATK都回归稳定期水平 |
| **代价** | 同时降低敌军ATK——意味着你自己的M1输出也被压制。在再灌注期用=保命，但也放弃了一波高伤害清场的机会 |
| **临床映射** | 真实药理学：依达拉奉是自由基清除剂，用于急性脑梗死再灌注损伤的神经保护 |
| **策略深度** | 再灌注期是双刃剑——友军ATK暴涨可以快速清场，但自伤也翻倍。依达拉奉让玩家选择"安全打法"还是"风险打法" |

### 5.4 三相对Eh轴的影响

```
缺血期:  Eh轴整体左移（偏还原）→ 所有单位DEF↑ ATK↓
         但这是被动的、病态的，不是战术选择

再灌注期: Eh轴剧烈右移（爆发氧化）→ 所有单位ATK暴涨
         M1态单位受益最大（Eh本来就高，再叠加暴涨）
         M2态单位也会被迫"氧化"——M2的防御优势在再灌注期被削弱

稳定期:  Eh轴回归中性 → 数值正常
         M2态优势回归（修复+30%）
```

## 6. 与Eiko战斗设计的整合

### 6.1 Eh轴替代原ATK/DEF双值

Eiko战斗策划案中的数值表需要从"ATK(M1)/ATK(M2)"双值改为"Eh基础值+极化系数"：

| 等级 | Eh基础值 | M1极化系数 | M2极化系数 | HP | 移动力 | 感受域 | α-KG容量 |
|---|---|---|---|---|---|---|---|
| Lv.1 | 450 | 1.8 | 0.4 | 6,000 | 4格 | 3格半径 | 5 |
| Lv.30 | 900 | 1.8 | 0.4 | 12,000 | 5格 | 4格半径 | 7 |
| Lv.50 | 1,500 | 1.8 | 0.4 | 20,000 | 5格 | 5格半径 | 9 |
| Lv.80 | 2,500 | 1.8 | 0.4 | 35,000 | 6格 | 6格半径 | 12 |

> M1极化系数1.8 = M1态ATK = Eh基础值×1.8
> M2极化系数0.4 = M2态ATK = Eh基础值×0.4
> 监视态ATK = 0
>
> 对比原表：Lv.1 M1 ATK=800 ≈ 450×1.8=810 ✓
> Lv.1 M2 ATK=200 ≈ 450×0.4=180 ≈ 200（取整差异） ✓

### 6.2 误伤友军=氧化自伤

原策划案中"M1炎症场溅射=Eiko攻击力×15%"的规则，现在有了解释：

```
氧化自伤 = M1态ATK × (1 - 极化系数) = M1态ATK × (1-0.85) = M1态ATK × 15%
```

> *炎症因子不分敌我——这不是游戏设计的随意选择，是氧化还原势的必然推论。*

### 6.3 目标类型修饰影响吞噬伤害

Eiko的吞噬技能对寄生虫几乎无效（修饰系数0.05），但玩家可能不会立即意识到——直到他们在寄生虫关卡中发现Eiko"打不动"。

> *这是暗度陈仓的终极形态：玩家会自己学会"小胶质细胞不是万能的"。*

## 8. 待决策点

以下三个问题源自初始提案，尚未由Senpai确认：

### Q1: 极化弹性是否可培养？

- **选项A**：可培养——玩家可以投入资源提升极化弹性，让M1↔M2切换更快更便宜
- **选项B**：固定值——只随角色升级自然成长，不可单独培养
- **倾向**：选项A——可培养增加build深度，且ATAC-seq数据可以量化

### Q2: 感受域在非SRPG模式中是否生效？

- **选项A**：全局生效——解剖探索中也影响能发现隐藏区域的范围
- **选项B**：仅SRPG生效——其他模式用独立机制
- **倾向**：选项A——减少系统碎片化

### Q3: 是否加隐藏"适应度"属性？

- **选项A**：加——类似舰R的"幸运"，影响跨地形作战和抽卡概率
- **选项B**：不加——避免暗箱属性影响竞技公平
- **倾向**：选项B——SoMe的暗度陈仓已经够多了，再加隐藏属性会让玩家不信任系统
