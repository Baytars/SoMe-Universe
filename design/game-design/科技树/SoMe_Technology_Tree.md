## 设计哲学

### 阵营核心主题：永生的诅咒

| 主题 | 生物学基础 | 游戏表现 |
|------|-----------|---------|
| **永生** | 端粒酶激活、DNA修复增强 | 单位持续回复、死后短暂复活 |
| **腐朽** | 基因不稳定、代谢紊乱 | 单位随时间累积突变（增益/减益随机） |
| **侵蚀** | 肿瘤微环境改造、血管生成 | 地图永久损伤、地形变形 |
| **扩散** | EMT、外泌体、CTC播散 | 远程播种、单位空投 |

### 医学隐喻体系

- **资源「营养素」** = 葡萄糖、氨基酸、脂肪酸（肿瘤掠夺性摄取）
- **能源「ATP」** = 细胞能量货币（瓦氏效应核心）
- **人口「细胞数」** = 肿瘤负荷/肿瘤大小
- **人口上限「微环境容量」** = 肿瘤微环境承载力

## 核心基础设施

### 1.1 基地核心：干细胞巢穴 (Stem Cell Niche)

> *"每一个癌细胞的祖先，都曾是一颗沉睡的干细胞。"*

| 属性 | 值 |
|------|-----|
| **医学对应物** | 肿瘤干细胞巢(Niche)/干细胞龛 |
| **解锁条件** | 游戏初始 |
| **建造时间** | 0秒（初始存在） |
| **能量消耗** | 无 |
| **人口容量** | +20 |

**功能：**
- 基地核心，不可移动，不可摧毁（被攻击时触发全图警报）
- 解锁所有基础建筑建造权限
- 干细胞巢穴被动效果：所有友军单位获得「干性维持」—— 每30秒恢复5%生命值

**升级选项：**
- [微环境优化] → 解锁更多人口容量
- [干性增强] → 提高干性维持回复量

### 1.3 能源建筑：代谢发电厂 (Metabolic Power Plant)

> *"有氧呼吸太慢，糖酵解才是效率。"*

| 属性 | 值 |
|------|-----|
| **医学对应物** | 瓦氏效应(Warburg Effect)/糖酵解代谢 |
| **解锁条件** | 干细胞巢穴已建造 |
| **建造时间** | 20秒 |
| **产出** | +25 ATP/秒 |

**运作机制：**
- 基础版本：高效糖酵解工厂，产出高但产生「代谢废物」—— 周围友军单位攻速-5%
- 可研究升级消除此debuff

**变体建筑：**

| 变体 | 解锁条件 | 效果 |
|------|---------|------|
| **氧化磷酸化电厂** | 代谢适应科技 | 产出+40 ATP/秒，无代谢废物，但需要更多营养素 |
| **混合代谢电厂** | 代谢重编程科技 | 平衡产出，可切换模式 |

## 科技树依赖图

### 基础设施层

```
干细胞巢穴 ──┬── 营养汲取站
             ├── 代谢发电厂
             └── 分化研究所 ──→ 支援科技I
```

### 支援科技I 解锁项

```
支援科技I ──┬── 端粒酶激活 ──→ 干细胞维持 ──→ 永生协议
            ├── 代谢重编程 ──┬── 瓦氏效应 ──→ 代谢灵活性
            │                 └── 解锁: 代谢暴君
            ├── 血管生成因子 ──→ 微环境改造
            ├── 免疫逃逸理论 ──→ 检查点封锁
            ├── 突变加速器 ──┬── 基因不稳定 ──→ 耐药机制
            │                └── 解锁: 突变熔炉
            └── 外泌体通讯 ──→ 群体感应
```

### 兵营科技树

```
兵营 ──┬── 基底克隆兵
       ├── 快速分裂者 ⚠ 需分裂进化I
       ├── 免疫驯化者 ⚠ 需免疫逃逸
       └── 调节性T细胞 ⚠ 需免疫驯化者已生产
```

### 战车工厂科技树

```
突变熔炉 ──┬── 循环肿瘤载体 ⚠ 需EMT
           ├── 淋巴扩散车 ⚠ 需淋巴管新生
           ├── EMT转化器
           ├── 逆转化重甲 ⚠ 需EMT转化器
           ├── 多药耐药堡垒 ⚠ 需耐药机制
           └── 靶向药抵抗者 ⚠ 需MDR堡垒
```

### 超级武器解锁

```
超级武器解锁条件矩阵：

肿瘤爆发 ──────── 突变加速器 + 微环境改造
永生祭坛 ──────── 端粒酶激活 + 干细胞维持
代谢风暴 ──────── 瓦氏效应 + 代谢灵活性
转移扩散 ──────── EMT转化器 + 淋巴管新生
```
