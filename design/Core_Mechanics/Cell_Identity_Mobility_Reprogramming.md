### 0.1 拟人尺度分层（铁律，主人 09-18 拍板）
SoMe 拟人严格按生物组织尺度分层，**跨层不得共用同一位格/神格**：

| 尺度 | 存在 | 社会位格 | 本母题例子 |
|---|---|---|---|
| 细胞/社会层 | 一个细胞（公民） | 细胞社会里的人、职业、圣徒 | **白衣天使**＝被封圣的**细胞**（飞翼女医的追认） |
| 细胞内层·分子 | 转录因子/蛋白（细胞内部执行机制的官吏） | 细胞核朝廷里的命官、胥吏 | **翼印官＝FoxA 蛋白**，在核内剪开身份档卷 |
| 技术/事件层 | 重编程（一套程序） | 调令制度/回炉工程 | Reforging、一块砖 |

- **白衣天使与翼印官是两个独立形象**：前者是细胞层、被社会记忆封圣的医者；后者是分子层、核内执行改籍的无名官吏。**不是同一原型的祖形与回响，不共享神格、不混传记。**
- 唯一可留的是**形态的偶然同构**：FoxA 结构域恰名 winged-helix（翼状螺旋），分子官吏故"佩翼钥"；与细胞层飞翼圣徒视觉上遥相呼应，但叙事不点破、不追认亲缘——像两位素不相识、恰好佩同款纹章的官员。
- 推论：翼印官在细胞**之内**，是细胞无法直接看见的体内齿轮。世界内宜处理为**细胞对自身机制的半神话化想象**（民间传闻"核中有持翼钥开门的小吏"），而非一个与白衣天使并列受祭的神。

## 1. 科学底座（已核实，2026-09 检索）

### 1.1 两条技术路线
- **经多能态（iPSC 路线，间接）**：终末细胞 → 多能干细胞 → 再定向到任意胚层。通用、可扩增；绕路，有成瘤、衰老重置、印记异常风险。Yamanaka 四因子 **OSKM = Oct4 / Sox2 / Klf4 / c-Myc**。
- **直接重编程（transdifferentiation）**：不经过可检测的多能中间态，靠转录因子或小分子直接改写身份。更快、可原位（in situ）、保留来源细胞表观与年龄记忆；但**效率低、产物常不成熟**。

### 1.2 跨胚层是"身份并非世袭"的最强证据
成纤维细胞（**中胚层**）是最常用的"万能供体"，可被直接转为肝、胰等**内胚层**细胞：

| 转化 | 因子/手段 | 里程碑 |
|---|---|---|
| 成纤维 → 肝细胞 iHep（鼠） | **Hnf4α + Foxa1/2/3**（Sekiya & Suzuki）；**Gata4 + Hnf1α + Foxa3**（Huang；尾成纤维需敲低 p19^Arf） | 2011，两组同时 |
| 人成纤维 → iHep | HNF1A/HNF4A/FOXA 等多因子，部分方案需敲低 TP53 | 2014 |
| 成纤维 → 肝（**CRISPRa 内源激活**） | 只激活内源 **Gata4/Foxa3/Hnf1a**，不转入外源 cDNA；AAV6 体内递送可减轻肝纤维化 | 2024 |
| 成纤维 → 肝（**纯小分子 CiHep**） | 化合物逐级激活内源 Foxa1/2/3、Hhex、Hnf1b、**Hnf4α**；经"内胚层/胚外内胚层样"多谱系预置态（CaMP）；可在 FRG 小鼠体内**重建肝实质、挽救肝衰** | 北大赵扬组，*Hepatology* 2022 |
| 骨骼肌 → 早期内胚层（**体内、两因子**） | 斑马鱼异位共表达 **Sox32 + Oct4**，走 sox17→ptf1a、依赖 FGF 的近似胰程序；Oct4(L80A)（不能诱导多能）仍成立 → **不需多能中间态** | Espin lab |
| 胰外分泌/α 细胞 → β 细胞 | **Ngn3 + Pdx1 + MafA**（同属内胚层，非跨层，作对照） | 体内重编程首例之一 |

**反向（内胚层→中胚层）直接证据明显稀缺**：缺少像 Hnf4α+Foxa 那样干净的两因子配方，主流仍绕 iPSC。原因——内胚层上皮身份由强自维持网络（HNF4α、FoxA 的 bookmarking）锁定，且反向需先跨 EMT。**这道墙不对称：下行（成纤维→肝胰）有门，上行（肝胰→血/肌）几乎只能回白板重造。**

### 1.3 机制（叙事时的"硬约束"）
1. **先锋因子 pioneer factor**：**FoxA 家族（forkhead / winged-helix 翼状螺旋结构域）**能直接结合致密核小体，先"书签式"撬开标靶位点，后续 HNF4α/Gata4 才进得去。它几乎出现在所有成纤维→肝配方里 = **跨阶层的"破门锤/改籍官"**。　**包装袋比喻（主人 09-18 钦定）**：把一个细胞的身份看作一袋已封装好的内容——**FoxA 是在包装上剪开第一口的人**（pioneer 在板结染色质上开口、bookmarking 留缝），**Hnf4α 是把内容调整完毕后重新封口的人**（建立自维持的肝身份网络）。没有第一剪，封口无从谈起；只剪开却没人重新封口，袋子就永远敞着（卡在 CaMP 见习态）。
2. **MET / EMT**：中胚层成纤维（间充质）→内胚层上皮需先 MET；反向需先 EMT。身份跨界要先"脱胎"。
3. **不回山顶**：直接重编程常走一条**经过目标胚层祖细胞样状态的捷径**（CiHep 的内胚层样态、斑马鱼的早期内胚层态），而非翻回 Waddington 山顶；单细胞轨迹另见大量细胞走 "refractory route" 被原命运拉回 → 解释低效率。
4. **产物不成熟 + 表观记忆**：iHep 常呈高 AFP / 低 ALB 的胎肝表型；直接重编程保留来源细胞的年龄与表观烙印。**改了岗位，洗不掉出身。**
5. **半途即癌**：体内重编程若信号被提前终止，细胞获得无限增殖却没建成新身份网络 → 表观恶性（无基因突变，类似 Wilms 瘤）。→ 已用于序章《SABOTAGED GENESIS》(Ohnishi et al., *Cell* 2014)。
6. **T↔AT2 是最远的一道墙**：T 细胞（中胚层造血/淋巴）↔ II 型肺泡上皮（内胚层）**没有**被验证的直接配方；现实路径只能 T/iPSC/确定性内胚层/Nkx2-1⁺ 肺祖细胞/AT2，且 T 细胞来源还带 TCR 重排的表观包袱。AT2 侧的直接转化证据本就薄。

## 3. 母题内核："革命一块砖，哪里需要哪里搬"

### 3.1 崇高面——再生医学的奉献伦理
- 一个成纤维细胞（普通结缔组织"泥瓦匠"）被一纸调令改造成肝细胞、心肌、神经元：**个体放弃天生身份，去补共和国最缺的那块墙**。
- 砖的意象=标准化、可牺牲、以整体建筑为意义。这与战后重建、Phoenix Liberation 后的城市修复在情感上同源。
- **金句候选（世界内口号/誓词，待主人定稿）**：
  > "We are fired for whatever wall the body builds."（我们为身体要砌的任何一堵墙而烧制。）

### 3.2 阴影面——同一套话语的两种读法（必须两面都写）
| | 崇高读法 | 阴影读法 |
|---|---|---|
| 调令 | 志愿请缨、人尽其才 | 强制征用、剥夺自我 |
| 回炉 | 重新做人的机会 | 抹除履历、消失的旧我 |
| 一块砖 | 无名英雄的奉献 | 个体被工具化、谁在决定"哪里需要" |
| 不完全重编程 | —— | 动员半途被弃，沦为失序者 |

**叙事戒律**：不能只把"砖"写成浪漫。真正的重量在于——**谁有权下这道调令？被搬走的砖有没有选择权？** 这把母题从口号提升到悲剧，也天然对接 restore vs exploit（提权范式）和 Umin 的"强制去分化"。

### 3.3 与既有阵营/角色的咬合（已检索，无冲突）
- **Yukio 的 nuclear reprogramming 研究背景**：她是"调令科学"在正典里最自然的内行/良心位——既懂回炉之术，又警惕它被征用。
- **MARY-07 / 拟态者**：越界伪装不是化妆，是**一整套染色质级身份重写**；能从中境战士伪装成内境守湖人者，要么借"白板再造"（iPSC 级重置，代价与痕迹都极大），要么手握"翼印调令官"（FoxA 级先锋因子）。髓院 mTEC/AIRE 的 self 识别，正是在这条表观边界上抓"假户籍"。
- **军民融合·肺泡开放口岸（主人 09-18 钦定，内→中的真身）**：内胚层→中胚层的"跨越"在现实里**不是"民被改籍成兵"**，而是**中境免疫者常驻内境民间**——肺泡湖是面向大气的开放口岸，本就军民混防：淋巴细胞/肺泡巨噬细胞（中境）巡逻，**BALT 支气管相关淋巴组织＝湖区驻防营**；AT2 渔民补湖岸、泌 surfactant，敌袭时分泌细胞因子＝民转警报情报。**驻防是制度允许的跨界（身份不变），重编程才是改写身份本身——两层必须分开。** Yosemite 童年在湖岸见过巡逻的淋巴细胞：戴甲的中境兵巡过口岸，兵民天天照面却分属两界，是她"民境见军"的第一幕。
- **Yosemite 身世的毒理闭环（geisha＝供烟）**：身份定为肺泡细胞（开放气体交换口岸的 AT2）后，被卖进 okiya 有了碳基对应——**她被卖去专供香烟，掠夺者要的货物是尼古丁**。呼吸膜在 I 型细胞处仅约 0.5μm，尼古丁是脂溶性小分子，吸入后**数秒**即跨肺泡—毛细血管膜入血（成瘾起效极快的原因）；一个本应修补湖岸、分泌表面活性物防湖面坍缩的 AT2，被劫持成成瘾物入血的通道。慢性吸烟还诱导 AT2 衰老、抑制 surfactant（COPD/肺气肿的细胞底子）。写法＝一个被调离修补岗、强征进烟馆的细胞之悲剧，克制不渲染。
- **尖锐互文（仅 Design 层，勿进正典台词；事实已订正 09-18）**：从福岛核火里把她救出、三周吸尽辐射的是 **Franklin**（白袍、洁净），随后 Franklin 把她带到 **Grand Duchess Victoria** 面前；而 Victoria 那间"闻起来是烟斗烟草味"的书房（Yosemite 正典 §The Rescue），正是收容她、给她新生的权力中心。于是一个刚从尼古丁烟馆里被赎出的肺泡细胞，被领进的庇护宫廷也飘着同一种气味——**毒不在加害者身上独占，它弥漫在庇护所的空气里**。救人者洁净，安置她的秩序却与旧奴役共享一种味道。
- **湖民↔巡逻兵的阶层张力**：内境渔民与中境哨兵同守一片湖却界别森严，为日后免疫阵营人物相遇垫"熟悉又疏离"的底色。
- **翼印官（FoxA，分子层，与白衣天使独立）**：定位为**细胞核内剪开身份档卷的无名分子官吏**。三拍——翼痕（FoxA 剪口）→候补（CaMP 悬空）→盖印（Hnf4α 封口）；悲在"剪开即退场，封籍署名的是盖印者"。她不进入器官成形队伍，也不与飞翼女医共享神格。世界内只作为细胞对体内机制的半神话想象（"核中有持翼钥的开门小吏"），不设庙、不与白衣天使并列。尺度见 §0.1。
- **序章 Reprogramming Engineer / OSKM**：已属"回炉派"事故叙事，本档为其补全社会身份语义（半途动员=失序者）。
