## 一、核心命题

**SoMe 的世界不是"基于生物设定的幻想世界"——它就是一个碳基计算系统。**

**玩家不是"在生物世界冒险的角色"——他是一个坠入碳基计算系统的外部意识。**

**玩家的成长不是"打怪升级"——他是从一个不懂系统的外来者，成长为碳基黑客。**

这三句话重新定义了 SoMe 的叙事层。此前 SoMe 的所有设定——代谢 Homoiconicity、Alopes 公国、Umin 战争、三大玩法维度——都是平行的线索。"碳基赛博空间"把它们编成了一根绳。

## 二、本体论基础——这不是比喻

### 2.1 前提

《代谢 Homoiconicity》已确立：TCA 循环是碳基实现的 Lisp——代码即数据，数据即代码。α-KG 既是燃料（被 TCA 氧化执行 = `eval`），又是控制信号（作为 TET/JmjC 辅因子改写基因表达 = `quote`）。这不是类比，是**结构同构**。

如果碳基生命在分子层面就是计算系统，那么"碳基赛博空间"不是把生物世界"比喻"成电脑——它是在**描述**生物世界的真实本质。

### 2.2 与现有"异世界"叙事的根本区别

| 作品 | "数字世界"的本质 | 真实 vs 虚拟 |
|---|---|---|
| Sword Art Online | 人造硅基虚拟空间 | 虚拟（人造服务器） |
| The Matrix | 机器构建的模拟世界 | 虚拟（机器造的） |
| .hack// | 游戏内的游戏世界 | 虚拟（嵌套虚拟） |
| Re:Zero | 异世界召唤 | 异世界（平行世界） |
| **SoMe** | **真实存在的碳基计算系统** | **真实（生物计算即真实计算）** |

SoMe 的"赛博空间"不是任何人造的虚拟世界。它是 40 亿年化学演化自发涌现的计算系统——你的身体。没有"真实 vs 虚拟"的对立，因为生物计算**就是**真实计算。

> *其他作品里的"赛博空间"是人造的。SoMe 里的赛博空间是进化出来的。*

**据我们所知，没有游戏做过这件事。**

### 2.3 核心洞察

玩家以为自己在玩一个"跌入赛博空间的黑客幻想"。
实际上他在学习用计算思维理解自己的身体。
而且因为"hack"用的全是真实生物规则，知识直接迁移。

这就是「暗度陈仓」的终极形态。

## 三、碳基计算栈——世界架构

### 3.1 三层抽象

直接继承《代谢 Homoiconicity》的三层架构，映射为游戏世界结构：

```
┌─────────────────────────────────────────────────────────────┐
│  应用层 — 细胞类型编译器                                      │
│  不同细胞类型 = 不同编译器，将共享字节码编译为不同输出          │
│  神经元 → 编译 α-KG 为谷氨酸 / GABA                          │
│  免疫细胞 → 编译 α-KG 为精氨酸 / NO                           │
│  肿瘤细胞 → 劫持编译器，输出 2-HG                             │
│  → 对应游戏：不同"区域"的本地程序有不同功能                    │
├─────────────────────────────────────────────────────────────┤
│  字节码层 — α-酮酸池                                          │
│  α-KG / OAA / 丙酮酸 = 通用中间资源                           │
│  路由决策 = "哪个编译器获得燃料"                               │
│  → 对应游戏：玩家可操作的"资源路由"策略层                      │
├─────────────────────────────────────────────────────────────┤
│  汇编层 — TCA 循环                                            │
│  自动运行的内核守护进程                                        │
│  消耗 Acetyl-CoA + OAA → 产出 ATP + 3 种 α-酮酸               │
│  → 对应游戏：世界的心跳，始终在背景运行                        │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 世界映射

| 生物概念 | CS 概念 | SoMe 世界元素 |
|---|---|---|
| TCA 循环 | 内核守护进程 | 世界的心跳——线粒体火 |
| α-KG | root access token | 决定哪些"代码"可执行的关键资源 |
| TET / JmjC 酶 | 权限管理系统 | 擦除/授予基因组的"执行权限" |
| 染色质状态 | 文件系统权限 | 哪些基因组区域"可读写" |
| 细胞类型 | 编译器实例 | 不同"区域"的本地程序 |

| 信号通路 | 网络协议 | 角色间通信机制 |
| 免疫系统 | 安全防御系统 | 公国的军事-医疗力量 |
| 补体级联 | 自动化防御脚本 | 事件触发的连锁响应 |

| 病原体 | 恶意软件 | Umin |

| 神经元重编程 | 系统恢复 | 重启冻结的进程 |
| 脑梗死 | 核心区断电 + 指令集崩溃 | 系统级灾难事件 |

### 3.3 关键设计原则

**CS 术语是玩家的解读透镜，不是 NPC 的母语。**

NPC 不会说"α-KG 是 root access token"——他们说 α-KG（或 SoMe 世界中的对应名称）。但玩家作为"外来黑客"，逐渐学会用 CS 概念理解这个世界。这镜像了用户自己在 CS 课程中的学习旅程——先懂生物，再学 CS，然后看到两者的同构。

> *NPC 在用生物学语言生活。玩家在用计算思维解读。两者描述的是同一个系统。*

## 四、玩家旅程——双模主角设计

### 4.1 核心概念：双模主角

主角存在两种运作模式，对应叙事的两个大阶段：

**模式 A — 自系统（漂泊者模式）**

主角因缺血事件坠入碳基计算系统，丧失记忆。ta 不知道自己是这个系统的管理员——意识与生物底层的连接被灾难事件切断。但系统内的所有"本地程序"（细胞角色）本能地感应到 ta 的存在：这是它们的 root，它们的意识，它们一直在等待的"唤醒"。所有 NPC 对主角都有一种无法解释的特殊情感——如同《鸣潮》中的共鸣者对漂泊者。

这不是奇幻设定。这是免疫自我识别、细胞对宿主意识的生物学响应在叙事中的投射。每一个细胞都携带与玩家相同的 DNA——它们**就是**玩家的一部分，它们的"共鸣"是 self-recognition 的诗意表达。

**模式 B — 跨系统（Encounter 模式）**

顿悟之后，主角理解了自己的真实身份。此后，ta 可以进入**其他系统**——其他患者的碳基计算系统。此刻身份发生根本转换：从"失忆的本地 admin"变为"外来拯救者"。每一次进入都是一次 doctor-patient encounter——医生与患者的相遇。主角带来的不是本地知识，而是跨系统的 hacker 经验。

### 4.2 与《鸣潮》的映射

| 鸣潮 | SoMe | 根本区别 |
|---|---|---|
| 漂泊者失忆降临 | 玩家缺血坠入，忘记自己是 admin | 鸣潮是奇幻；SoMe 是生物真实 |
| 共鸣者对漂泊者有特殊情感 | 细胞本能识别"自己的意识"（self-recognition） | 鸣潮是设定；SoMe 是免疫学 |
| 漂泊者逐渐恢复记忆 | 玩家逐渐理解系统 = 逐渐"想起"自己是谁 | 鸣潮是找回过去；SoMe 是获得真知 |
| 漂泊者拥有特殊力量 | 玩家拥有"外部意识视角"——能做本地程序做不到的事 | 鸣潮力量来源是奇幻；SoMe 是神经元重编程 |
| 仅限自身世界 | 顿悟后可进入其他系统（Encounter 模式） | SoMe 独有——从漂泊者进化为游走 healer |

**关键区别**：鸣潮的漂泊者力量来源始终是奇幻设定。SoMe 的玩家力量来源是**真实的**——你之所以能 hack 系统，是因为你确实是这个系统的意识。你用的每个 hack 手段都是真实的生物机制。你的"共鸣"不是魔法，是免疫学。

### 4.3 叙事弧线

```
失忆 admin（不知道自己是谁）
    │
    │  模式 A：自系统 — 主线剧情
    │  NPC 帮你恢复系统 = 帮你想起自己
    │  所有 NPC 对你有"共鸣"——它们是你的细胞
    │
    ↓
顿悟 ★（我是 admin，这是我的身体）
    │
    │  模式切换——身份从"本地 admin"转为"外来 healer"
    │
    │  模式 B：跨系统 — Encounter 扩展
    │  你现在作为"外来专家"进入其他患者的系统
    │  每个新患者 = 一个新世界，每种疾病 = 一种故障模式
    │
    ↓
精通碳基黑客（游走于多个系统之间）
```

### 4.4 入场叙事（已确认）

**缺血事件 + 失忆坠入（方案 A + C 合并）**

玩家角色是一个普通年轻人，突发脑缺血事件（cerebral ischemia）。意识"坠入"受影响脑区的碳基计算系统——但坠入的冲击导致**失忆**。ta 不知道自己是谁，不知道这是自己的身体，只知道自己在一个正在崩溃的系统中醒来。

这个区域的"系统"正在崩溃——TCA 停转 → α-KG 耗竭 → TET 失活 → 表观遗传冻结 → 神经基因锁死。本地程序（细胞角色）正在拼命维持运行。它们感应到了"意识"的回归——它们的 admin 回来了——但 admin 自己什么都记不得了。

玩家作为"回归但失忆的 admin"，拥有不同于本地程序的视角（外部意识视角）。ta 开始"hack"系统：引导 α-KG 路由、激活 TET 酶、解锁冻结的基因——本质上就是在做**神经元重编程**。

**为什么这个方案最优：**

1. 缺血事件是失忆的原因——叙事因果链自洽
2. 失忆解释了为什么玩家不懂系统——ta 是 admin 但忘了怎么操作
3. NPC 的"特殊情感"有了生物学基础——self-recognition
4. 第一个任务就是神经元重编程——拯救缺血组织
5. 玩家的成长弧线 = admin 逐渐"想起"如何操作自己的系统
6. 顿悟时刻天然成立——"想起"的不是技能，是身份
7. 镜像用户自己的研究历程（神经内科 + 脑梗死 + 神经元重编程）
8. 与受众定位匹配——玩家熟悉"失忆降临异世界"的叙事模式

### 4.5 顿悟时刻

SoMe 的 "I am your father" 时刻——也是模式 A → 模式 B 的转换点：

玩家完成了第一个大弧线——拯救了缺血区域，恢复了系统运行。在高潮时刻，ta 看到了一面"镜子"——某种反射——意识到：

> *这个碳基赛博空间……就是我。*
> *那场系统崩溃……就是我的脑梗死。*
> *那些拼命帮我的本地人……就是我的细胞。*
> *我不是外来者。我是 admin。我一直都是。*

顿悟之后游戏继续，但维度完全打开。玩家现在理解了赌注，并且获得了新能力——**进入其他系统**。每个新患者 = 一个新的碳基赛博空间，带着不同的故障模式，等待这个"已觉醒的 admin"前来 encounter。

### 4.6 Encounter 模式——每个患者是一个新世界

顿悟后，主角可以进入其他患者的碳基计算系统。此刻叙事从"自我拯救"转向"拯救他者"——正是一次 doctor-patient encounter。

| 患者系统 | 故障类型 | 黑客任务 | 医学对应 |
|---|---|---|---|
| 癌症患者 | rogue process 肆虐 | 终止失控进程，恢复凋亡检查点 | 肿瘤学 / 细胞周期 |
| 自身免疫患者 | 安全系统误报 | 调整 IDS 规则，停止友好火力 | 风湿免疫 |
| 遗传病患者 | legacy code bug | 识别出厂缺陷，部署 workaround | 医学遗传学 |
| 感染患者 | 恶意软件入侵 | 威胁狩猎 + 清除 + 修补入口 | 感染病学 |
| 代谢病患者 | 内核资源分配失衡 | 重新校准 TCA 输出，修复路由 | 内分泌 / 代谢 |
| 神经退行性患者 | 内存泄漏 + 进程退化 | 清理错误折叠蛋白，重启清除机制 | 神经内科 |

**每个 Encounter 的叙事结构**：进入 → 遇到本地 NPC（患者的细胞）→ 诊断故障 → 执行 hack → 恢复系统 → 离开。这镜像了临床接诊的全流程。

### 4.7 多人模式（已解决）

模式 B 天然支持多人：
- 其他玩家 = 其他已觉醒的 admin / carbon hacker
- 各自管理自己的"自系统"（单人剧情）
- 可以互相进入对方的系统进行协作（**会诊**）或竞技
- "会诊" = 多个 hacker 协作处理一个复杂病例
- 这也解释了为什么不同 hacker 有不同专长——不同"科室"

### 4.8 NPC = 引导者 = 隐藏教师

用户说"在本地人的指引下"——NPC 不只是任务发放者，他们是**教师**。每个 NPC 教授碳基黑客的不同"模块"：

| NPC | 教授内容 | 对应 CS 课程模块 |
|---|---|---|
| Dr. Yuan Yukio | 基础系统规则——状态机、信号转导 | M1 状态机 / M3 事件驱动 |
| Minister Sazan | 内核原理——TCA 循环、代谢 ISA | M5 编译器 / M6 OS |
| Grand Duchess Victoria | 系统治理——权限管理、资源调度 | M4 OOP / M6 OS |
| 免疫角色 | 安全运营——入侵检测、防御部署 | M7 图论（网络防御） |

NPC 用生物学语言教学。玩家用计算思维理解。两种语言描述同一个系统——这就是课程"用生命系统学计算机科学"在游戏中的体现。

### 5.3 NPC 的认知层次

并非所有 NPC 都理解自己世界的本质：

| 认知层次 | 代表角色 | 理解程度 |
|---|---|---|

玩家从"日常认知"起步，在引导下逐步达到"深层认知"——成为真正的碳基黑客。

## 七、碳基黑客技能树 = 医学课程

玩家的技能成长不是"火球术 Lv.1 → Lv.2"，而是一棵**黑客技能树**，每个分支对应一个医学领域：

| 黑客技能 | 医学知识 | SoMe 玩法体现 | CS 课程模块 |
|---|---|---|---|
| **侦察** (Reconnaissance) | 解剖学 / 生理学 | 探索开放世界，理解系统架构 | M2 数据结构 |
| **漏洞分析** (Vulnerability) | 病理学 | 识别疾病机制，找到系统漏洞 | M3 事件驱动 |
| **利用** (Exploitation) | 药理学 / 治疗学 | 使用药物 / 干预 hack 系统行为 | M4 OOP |
| **防御** (Defense) | 免疫学 / 预防医学 | 部署防御策略对抗入侵 | M6 OS |
| **取证** (Forensics) | 病因学 / 发病机制 | 追溯疾病发展过程 | M7 图论 |
| **逆向工程** (Reverse Engineering) | 生物化学 / 分子生物学 | 拆解代谢通路，理解源代码 | M5 编译器 |
| **系统恢复** (System Recovery) | 神经元重编程 / 康复医学 | 重启冻结进程，恢复功能 | M8 ML |

**核心设计洞察**：玩家的技能树 = 医学院课程表。但玩家不知道——他们以为自己在学"黑客技能"。

> *暗度陈仓的终极实现：玩家以为自己在练黑客技能树，实际上他们在修完一个医学院。*

## 九、美学方向——碳基生物朋克

### 9.1 不是 Tron，不是 Cyberpunk

传统赛博空间美学：霓虹灯、电路板、黑色背景、几何线条——这是**硅基**赛博空间的美学。

SoMe 的碳基赛博空间应该有完全不同的视觉语言：

| 硅基赛博朋克 | 碳基生物朋克 |
|---|---|
| 霓虹色 | 生物荧光（GFP 绿、血色素红、胆色素黄） |
| 电路板纹路 | 血管 / 神经 / 淋巴管网络 |
| 几何线条 | 有机曲线与分形结构 |
| 黑色背景 | 组织切片的染色质感 |
| 数据流 | 代谢流（分子在通路中流动） |
| 服务器机房 | 细胞内部结构（核 / 线粒体 / 内质网） |
| 代码雨 | DNA 序列 / 密码子流 |
| 防火墙 | 血脑屏障 / 皮肤屏障 / 黏膜屏障 |
| 漏洞利用 | 药物靶向 / 病原体侵入 |

### 9.2 视觉关键词

- **有机计算** (Organic Computing)：电路是有机的，代码是分子的
- **生物荧光** (Biofluorescence)：不是 LED 发光，是酶催化发光
- **染色质感** (Stain Texture)：H&E / 免疫组化染色的色彩美学
- **微观史诗** (Microscopic Epic)：细胞核如同大教堂，线粒体如同熔炉
- **活体界面** (Living Interface)：UI 不是"叠加"在世界上的，是"生长"出来的

### 9.3 参考美学

- 《工作细胞》的细胞拟人化 + 微观世界尺度感
- H.R. Giger 的生物力学（去恐怖化，保留"有机 + 机械"的融合感）
- 《杀戮尖塔》的暗色系 + 符号化 UI
- 显微镜摄影的色彩与纹理

## 十、开放设计问题

以下问题留待后续设计迭代解决：

1. ~~**入场叙事最终选择**~~ ✅ **已确认（2026-07-11）**：方案 A + C 合并——缺血事件导致失忆坠入。玩家是"回归但失忆的 admin"。
2. **NPC 认知深度**：多少 NPC 知道世界的"计算本质"？这影响叙事的信息揭露节奏。
3. ~~**顿悟时刻的时机**~~ ✅ **已确认（2026-07-11）**：顿悟 = 模式 A → 模式 B 转换点。第一弧线高潮，既是身份揭示也是能力解锁。
4. **"黑客"操作的输入方式**：玩家如何"hack"？是命令行式？拖拽式？图谱式？
5. ~~**多人模式**~~ ✅ **已确认（2026-07-11）**：模式 B 天然支持——其他玩家 = 其他已觉醒 hacker，可互相进入对方系统协作（会诊）或竞技。
6. **与 SRPG 战斗系统的整合**：战斗中的"hack"操作如何与传统 SRPG 回合制融合？
7. **角色名 vs CS 术语**：NPC 在游戏中用什么名称称呼这些概念？（遵守 Rule 10：SoMe 专属术语不复用外来概念）
8. **SoMe 宇宙法则的扩展**：此前确立"生物法则 = 物理法则"，现在延伸为"生物法则 = 计算法则 = 物理法则"。三者是否等价？是否有生物法则无法归结为计算法则的情况？
9. **"共鸣"机制的游戏化**：鸣潮的共鸣者系统在 SoMe 中如何实现？玩家只能"hack"与自己"共鸣"的细胞——这在生物学上对应什么？（候选：MHC 匹配 / 组织相容性 / 受体-配体特异性）
10. **Encounter 模式的进入方式**：玩家如何"进入"其他患者的系统？叙事上需要什么理由和机制？
11. **失忆程度的控制**：玩家是完全失忆（不知道任何医学知识）还是部分失忆（保留常识但忘记专业能力）？这影响新手引导的设计。
