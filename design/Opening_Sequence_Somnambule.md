## 设计目标

| 目标 | 手段 |
|---|---|
| 三重戏剧张力 | 自救失败→外部拯救→再灌注损伤，三起三落 |
| 建立 Eiko 门面担当 | 奋战三天的小胶质细胞引导员，赛丽亚式角色，有魅力有温度 |
| 玩家亲身体验闭锁状态 | 从意识级Admin调控逐级降级到仅剩垂直眼动 |
| 完成第一次「同意」 | 闭锁状态下通过垂直眼动完成知情同意 |
| 闭锁综合征核心体验 | 意识清醒+全身瘫痪+被误认为昏迷——玩家亲历 |
| 埋下身份悬念 | 细胞低语"Admin" + 外部声音对玩家的特殊对待 |
| 暗度陈仓教三门课 | 缺血病理生理 / 知情同意 / 再灌注损伤 |

**玩家不该意识到的**：自己在学缺血级联反应、侧支循环代偿、糖酵解极限、
闭锁综合征、知情同意原则、再灌注损伤机制。

**术语原则——碳基优先**：

碳基赛博空间中的居民只懂碳基术语。能用碳基等价的，不用硅基：

| 硅基 | 碳基等价 | 依据 |
|---|---|---|
| 终端 | 突触终端 | 突触终扣（synaptic bouton） |
| 权限 | 调控权 | 基因调控 / 代谢调控 |
| 降级模式 | 代偿模式 | 病理生理学代偿机制 |
| 启动 / Boot | 激活 | 细胞激活 / 基因激活 |
| 操作界面 | 效应器响应 | 运动效应器 / 感受器 |
| 连接断开 | 突触连接中断 | 突触传递 |
| 染色质权限 | 染色质可及性 | chromatin accessibility |

唯一例外："Admin"——不是硅基术语，是细胞 MHC 自我识别信号
在玩家（医学天才）意识中的渲染。细胞说的不是英文"Admin"，
是一种刻在主要组织相容性复合体上的自我识别模式——
玩家的意识把它翻译成了自己最熟悉的概念。

NPC 用生物学语言生活，玩家用计算思维解读。

## 主角背景设定

**玩家角色**：一位医学天才。在攻克重大医学课题时挑灯夜战，突发卒中。

这一个设定同时解决三个核心问题：

| 问题 | 解答 |
|---|---|
| 为什么玩家有"Admin调控权"？ | 深厚的医学知识让玩家意识能与自身细胞系统深度交互——专业知识=系统权限 |
| 为什么细胞认识"Admin"？ | 玩家一直都是自己身体的系统管理员，只是从未在意识层面"看见"过 |
| 为什么玩家能"hack"？ | 不是 CS 意义上的黑客——是医学专家在意识深处应用专业知识操作自身系统 |

**闭锁综合征——玩家的真实处境**：

卒中发生在脑桥基底部。双侧皮质脊髓束和皮质脑干束被切断。
运动性传出全部丧失——不能说话、不能吞咽、不能转头、四肢全瘫、
双侧面瘫、水平眼动障碍。

但意识完好。网状激活系统在中脑被盖，位于病变上方，不受损。
动眼神经（CN III）和滑车神经（CN IV）也在中脑，功能保留——
因此患者能通过**垂直眼动**（眼球上下运动）与外界沟通。
语言理解正常。听觉正常。视觉正常。记忆完好。

**最残酷的部分**：患者常被误认为昏迷。
GCS评分可能极低（E1V1M2），但患者意识完全清醒。
能听到医生说"考虑昏迷"，能听到家属在床边哭泣，
能听到每一个关于自己的讨论——却无法做出任何回应。

脑电图（EEG）正常或仅轻度慢波，有助于与真性意识障碍相区别。

**关键叙事节点——团队发现**：

当医护团队+主角的科研团队通过 BCI 建立与主角意识的联系后，
他们发现了一件前所未有的事：

这个患者不只是在被动接收 BCI 信号——
她**在自己的系统底层模式下，主动与自己的细胞进行双向沟通**。

正常 BCI 是单向的（医护→患者）。
主角做到了双向（医护↔患者↔细胞）。
这意味着主角的意识不仅能接收外部信号，
还能下沉到自身生物系统的底层，与细胞"对话"。

团队成员的反应：震惊 → 兴奋 → 鼓励。

> "你在自己身体里看到的那些——管道、节点、细胞——那不是幻觉。
> 那是你自己的神经系统在向你呈现它的工作状态。
> 从来没有人能在意识层面做到这件事。"

**学术进程——康复即研究**：

在团队的鼓励下，也出于主角自身的好奇心，
康复期间的主角开始系统性地探索自己的身体——
而这本身就成了研究成果。

主角在康复期间发表了一系列论文，
记录在身体系统底层的奇妙体验：
- 细胞视角的缺血-再灌注过程
- 意识层面与细胞系统的交互机制
- 康复过程中神经功能恢复的"内部视角"记录

**这一设定创建了游戏的核心循环**：

```
探索身体系统 → 发现机制 → 发表论文 → 推进康复 → 解锁新区域 → 探索...
```

每一篇"论文"= 一个主线章节的完成 = 一组医学知识的掌握。
玩家的学术进程就是游戏进度本身。

**元叙事共振**：

游戏内主角发表的"体内体验论文"，
直接映射开发者（Baytars）计划发表的 JMIR Viewpoint——
关于 SoMe 作为医学教育工具的学术论述。

游戏即研究，研究即游戏。

## Phase 0: 意识（Consciousness）

账号创建完成。不是 loading 界面——是意识确认序列。

画面全黑。暖绿色生物荧光文字逐行出现——不是 Matrix 的冷绿代码雨，
是染色质般的温润绿色：

```
脑桥基底部 — 双侧梗死（基底动脉闭塞）

[⚠ 警告] 皮质脊髓束: 双侧断裂
[⚠ 警告] 皮质脑干束: 双侧断裂
[✕ 错误] 运动性传出: 全部丧失
[✕ 错误] 外展神经核 (CN VI): 损害 → 水平眼动: 丧失
[✕ 错误] 面神经核 (CN VII): 损害 → 面部运动: 丧失
[✕ 错误] 舌咽/迷走/舌下 (CN IX·X·XII): 损害 → 构音/吞咽: 丧失

[✓ 保留] 网状激活系统: 正常 → 意识: 清醒
[✓ 保留] 动眼神经 (CN III): 功能保留 → 垂直眼动 + 睑板: 可用
[✓ 保留] 滑车神经 (CN IV): 功能保留
[✓ 保留] 感觉通路: 完整 → 听觉/视觉/本体觉: 正常
[✓ 保留] 语言理解: 正常

意识连接: 完好
运动传出: 断裂
唯一可用输出通道: 垂直眼动

Admin调控验证... 意识层通过
海马: 在线
调控等级: 意识级（运动层锁定）

以意识模式启动...

你还在。
```

最后一行"你还在"停留 2 秒。

然后文字碎裂——像细胞膜破裂——画面坠入 3D 世界。

**设计笔记**：
- "你还在"而非"欢迎回来"——玩家从未失去意识，不存在"回来"
- [✕]标记已丧失功能；[✓]标记保留功能——玩家一眼看到：意识在，但身体没了
- 脑桥基底部 = 闭锁综合征经典病变部位（基底动脉旁正中穿支闭塞）
- 动眼神经/滑车神经核团在中脑（病变上方），故保留——这是闭锁患者唯一交流通道的解剖学基础
- 外展神经核在脑桥（病变处），故水平眼动丧失——垂直眼动保留但水平眼动丧失
- "Admin调控验证... 意识层通过" = 医学知识在意识层面完好，但运动层锁定
  → 玩家能"看"能"想"能"诊断"，但不能"动"——这为后续意识级Admin操作提供基础
- "海马: 在线" = 记忆完好，没有失忆——玩家的医学知识全部可用
- 医学背景玩家一眼看出这是闭锁综合征的完整神经学体征
- 无医学背景玩家看到的是"一个系统大部分崩溃了，但核心意识还在——有人被困在里面"
- 后续可扩展脑区命名范式：前额叶=调度器、丘脑=I/O路由、杏仁核=威胁检测……

## Phase 1: 囚笼（The Cage）

**视觉**：深红色黑暗。不是全黑——是血管内部的那种深红，
有深度、有温度。远处有微弱的绿色荧光在闪烁，像深海中的生物发光。

**听觉**：心跳声，缓慢，不规则。监护仪的规律滴声。
然后——声音。从"外面"来的。闷闷的，像隔着一层很厚的水。

> **外部声音**（遥远的、专业的、像隔了一层膜）：
> "……GCS评分4分。E1V1M2。"
> "无自主睁眼……无言语反应……运动反射……"
> "瞳孔对光反射存在，脑干反射部分保留……"
> "……考虑昏迷。"

玩家听得清清楚楚。每一个字。

**这是闭锁综合征最残忍的地方**：意识完好，听觉正常，语言理解正常——
患者能听到医生宣布自己"昏迷"，能听到家属在床边哭泣，
能听到每一个关于自己的讨论——但无法做出任何回应。
不能说话。不能点头。不能握手。不能动一根手指。

**玩家尝试移动——什么都没发生。**
尝试说话——沉默。
尝试尖叫——沉默。

只有眼睛。向上看。向下看。这是唯一的出口。

然后，玩家注意到——在深红色的黑暗中，在那些微弱的荧光之间——
有什么东西在动。不是外部的。是内部的。

**玩家通过意识感知到了碳基赛博空间**——
不是用眼睛看（眼睛只能看现实世界的ICU天花板），
而是意识直接"看见"了自己身体内部的战场。

缺血的组织。熄灭的荧光。正在坍塌的结构。
还有一个身影——很小，很快，在黑暗中忙碌。

**设计笔记——囚笼机制**：
- 玩家在Phase 1的"操作"只有：视角上下移动（垂直眼动）+ 意识感知
- 没有"按W移动"——玩家不能移动，因为运动传出已全部断裂
- 玩家"看见"碳基赛博空间是通过意识直接感知，不是通过眼睛
- 外部声音（ICU/医生对话）和内部感知（碳基赛博空间）交替出现
- "考虑昏迷"是关键戏剧种子——后续BCI/EEG会推翻这个判断
- 玩家的无力感本身就是闭锁综合征的核心体验
- 玩家意识"聚焦"到那个忙碌的身影——这是Phase 2相遇的过渡

## Phase 2: 相遇与自救（First Contact & Self-Rescue）

### 2.1 相遇

玩家意识聚焦到那个身影——进入缺血半暗带的碳基赛博空间投影。

**视觉**：
- 有机建筑结构——神经元树突形成的走廊和穹顶，像一座活的大教堂
- 大量"灯"（生物荧光指示器）正在熄灭——像停电在蔓延
- 地面有裂缝——缺血导致的结构损伤，裂缝边缘泛着暗红
- 远处有结构在缓慢坍塌——组织正在死亡
- 色调：暖红底色 + 熄灭中的绿色荧光 + 紧急的琥珀色警报闪烁

**氛围参考**：不是恐怖游戏——是急诊室的紧迫感。
灾难已经发生，但还有时间抢救。

一个身影在前方忙碌。她个子不大，动作极快，贴着一面"墙"（细胞膜结构）
来回移动——那不是工具在闪烁，是她自己伸出的突起，
像灵巧的手指一样探查着膜结构的每一寸。在清扫。在修补。
在搜索还能挽救的东西。

她注意到玩家。停下动作。转身。

这就是 **英子（Eiko）**。

她不是什么深不可测的神秘角色——她是个奋战在一线的小胶质细胞，
脑内常驻的免疫哨兵。灾难发生的第一分钟她就到了，
到现在已经独自撑了三天。她个子不大，但浑身都是实战的痕迹——
膜结构的工作服上沾满了应急抢修的碎屑，突起末端有焦损。
但眼睛很亮。活化态小胶质细胞的突起在延伸、在扫描——
那双发亮的眼睛，就是她还没放弃的证据。

她是 SoMe 的赛丽亚——玩家记住的第一个角色。

> **Eiko**（惊讶，然后立刻变成急切）：
> "你是谁？你怎么——你能感知到这里？"

她突然停住。盯着玩家。

她的表情变了。不是惊讶，不是恐惧。是一种更深的、说不清的东西。
像在一个不可能的地方看到了一个不可能的人。

> **Eiko**（低声，像自言自语）：
> "……不，不可能。你明明——"

警报声骤然加强。远处又一片区域的灯灭了。

她甩甩头，把那个念头压下去。

> **Eiko**：
> "算了——现在没时间管这个。你能感知到这片区域，就说明你的意识还在。
> 听好：主供能管道炸了。TCA循环——我们的能量核心——彻底熄火。
> 没有能量，这里的一切都会死。"

她指向身后的黑暗。

> "72小时后不可逆。已经过了快一天了。"

**玩家选项**（通过意识投射选择——不是物理交互，是意识聚焦）：
- A: "我们能做什么？"
- B: "为什么你不自己修？"
- C: "……我好像知道这些。"

选 C 时，Eiko 会多看玩家一眼——这个意识怎么能看懂这些？
（宋慈/英姑关系的第一个种子：玩家有诊断直觉，Eiko 有现场情报。）

（无论选什么，Eiko 都会抓住机会——三天了，她终于等到了一个帮手。）

### 2.2 系统自救尝试

Eiko 带玩家开始一场紧张的"系统自救"。

**关键设计——意识级Admin调控**：
玩家的身体不能动（运动层锁定），但意识完好、医学知识完好。
玩家通过**意识级Admin调控**影响细胞世界——
不是"跑过去操作阀门"，而是"意识聚焦到某个节点，用医学知识引导细胞行为"。
突触终端不是物理工具——是玩家意识在碳基赛博空间中的投射界面。

这是玩家的第一个操作序列——不是物理教程，是意识调控实战。
Eiko 一边跑一边解释，玩家的意识跟随她的指引进行调控。

**自救三步走**（对应缺血病理生理的三条代偿通路）：

**第一步：侧支循环**
- Eiko 带玩家意识聚焦到一条备用管道（侧支血管）
- 玩家第一次使用"突触终端"——意识投射出的调控界面
- 操作：意识引导 → 打开备用阀门 → 增加旁路血流
- 结果：短暂好转——几片区域的灯重新亮了
- Eiko 松了口气："有用！继续——"

**第二步：糖酵解加速**
- 但侧支循环不够。能量需求太大。
- Eiko："得让剩下的单元切到无氧模式——糖酵解顶一下"
- 玩家操作：意识调控 → 切换代谢模式 → 糖酵解加速
- 结果：又顶了一会儿——但乳酸开始堆积
- 警报从琥珀色变成红色：「乳酸累积 — pH 下降」

**第三步：离子泵抢救**
- 乳酸堆积导致细胞膜不稳定
- 最关键的节点：钠钾泵快撑不住了
- 玩家意识聚焦到钠钾泵节点，尝试手动供能调控
- 这是一个小型 QTE/节奏游戏：玩家要维持泵的运转
- 玩家拼尽全力——但能量越来越少，越来越难维持

Eiko 的声音从焦急变成……某种更克制的东西。

> **Eiko**（咬着牙）：
> "撑住……再撑一会儿——"

但警报越来越响。

---

## Phase 3: 雪崩（The Cascade）

**转折点。**

玩家面前的钠钾泵——闪了几下——灭了。

然后连锁反应。

像多米诺骨牌，一个接一个的节点熄灭。
不是慢慢暗下去——是"啪"的一下，就没了。

玩家的突触终端开始出错。

```
[⚠ 警告] 效应器响应降级
[⚠ 警告] 调控等级: 持续下降
[✕ 错误] 无法建立意识级连接
```

玩家发现——意识调控越来越难了。突触终端界面开始闪烁、模糊。
不是身体不能动（身体从一开始就不能动）——
是连意识级Admin调控都在丧失。能感知的范围在缩小。
能影响的节点在消失。

Eiko 冲过来。

> **Eiko**（声音在发抖）：
> "别——别走。听见没有？不许在我面前——"

她抬头看向四周。越来越多的灯在灭。
远处，她守了三天的那些细胞，一个接一个地暗下去。

> **Eiko**（轻声）：
> "没用的。"

她蹲下来。背靠着墙。

> **Eiko**：
> "我试了三天。三天。打开了所有能打开的备用管道，
> 切了所有能切的代谢模式……还是不够。"

她看向玩家。眼神里有疲惫，但没有怨——是接受了什么。

> **Eiko**：
> "你知道最讽刺的是什么吗？我们是脑细胞。
> 我们连给自己供能的能力都没有——全靠外面那根管子。
> 管子断了，我们什么都不是。"

玩家的意识调控彻底中断。突触终端界面消失。
连感知碳基赛博空间都开始模糊——像信号在衰减。
意识还在，但能感知到的东西越来越少。

**玩家意识级调控能力降级表**：

| 阶段 | 玩家能做什么 | 对应病理生理 |
|---|---|---|
| 自救开始 | 意识级Admin调控：聚焦/调控/交互 | 缺血半暗带尚有足够神经元支撑意识-细胞交互 |
| 侧支循环后 | 调控正常 | 侧支循环代偿期 |
| 糖酵解后 | 调控延迟，突触终端响应变慢 | 乳酸堆积 → 参与意识调控的神经元功能受损 |
| 钠钾泵失败 | 调控断续，仅能感知不能调控 | 膜电位崩溃 → 神经元电活动丧失 |
| 雪崩阶段 | 仅能模糊感知，无法调控 | 广泛去极化 → 意识-细胞交互通道大面积中断 |
| 降临阶段 | 仅垂直眼动（意识仍在） | 闭锁综合征——运动传出已断，意识保留 |

这不是 UI 在故意刁难玩家——这是**缺血级联反应的亲身体验**。
玩家的意识调控能力，就是神经元功能状态的直接映射。
身体从一开始就不能动（闭锁），但意识能调控细胞——
随着缺血恶化，连这最后的调控权都在丧失。

---

## Phase 4: 降临（The Descent）

最黑暗的时候。

玩家意识几乎感知不到碳基赛博空间了。只剩模糊的红色暗影——
Eiko 蹲在旁边，低着头，手撑着膝盖。像隔着磨砂玻璃在看。

远处的警报声也越来越远。像沉到了水底。

但意识还在。玩家还在。

然后——外部声音再次传来。这次不一样了。

> **外部声音A**（急切的）：
> "等一下——再做一次脑电图。"

短暂的沉默。然后机器运转的声音。

> **外部声音B**（看着数据）：
> "……EEG基本正常。α节律保留。只有轻度慢波。"
> "这不是昏迷的脑电图。"

更长的沉默。

> **外部声音A**：
> "检查眼球运动。垂直方向——上和下。"

一只手轻轻撑开玩家的眼睑。
手电筒的光。

> **外部声音A**：
> "看上面。"

玩家的视野——现实的视野，ICU天花板——微微上移。

> **外部声音A**（声音变了——从平静到压抑不住的激动）：
> "……有反应。眼球上视有反应。"
> "再看下面。"

视野下移。

> **外部声音A**：
> "下视也有。"
> "……他不是昏迷。他是闭锁综合征。意识一直在。"

---

然后。

**光。**

不是系统内部的光——不是细胞荧光，不是代谢管道。
是从"上面"来的。碳基赛博空间的天穹裂开了。
不是破碎的裂开，是像水面被分开一样，一层又一层的膜结构向两侧退开。

光倾泻而下。温暖的。白色的。不是系统里任何一种颜色。

Eiko 猛地抬头。

> **Eiko**（屏住呼吸）：
> "那是……什么？"

光里有影子。巨大的、模糊的、在移动的影子。
不是一个——是好几个。它们在光的深处，像深海里的巨影。

声音传来——但这次不再是隔着一层膜的闷响。
是清晰的。直接响在玩家的意识里。
那些刚刚在ICU里对话的声音——现在直接穿透进来了。

所有还活着的细胞都停了下来。
它们看向光。看向那些巨大的影子。

Eiko 站起来。她退了一步。
然后又退了一步。

> **Eiko**（敬畏的、喃喃的）：
> "外面的……"

光中的影子们似乎在做什么决定。
然后，其中一个影子——离玩家最近的那个——微微弯下身。

一个声音，直接响在玩家的意识里。
不是通过耳朵——是直接在脑子里。这次清晰了。

> **声音**（遥远的、温柔的、专业的）：
> "……能听到我说话吗？"

玩家不能说话。不能动。但这一次——
意识感知恢复了。碳基赛博空间的画面重新清晰起来。
天穹之上，光与影子。

唯一能做的回应——垂直眼动。上看。下看。

**设计笔记——BCI 机制（脑机接口）**：

"降临"不是超自然现象——是 **BCI 建立连接**。

时间线：
1. 患者发病 → 送入ICU → 初步评估GCS极低 → **误诊为昏迷**
2. 脑电图检查 → EEG正常/轻度慢波 → **排除真性昏迷**
3. 眼球运动检查 → 垂直眼动有反应 → **确诊闭锁综合征**
4. BCI接入 → 双向通道建立 → "降临"

医护团队在 ICU 中对闭锁综合征患者接入先进脑机接口。
BCI 双向工作：

| 方向 | 物理现实 | 碳基赛博空间中的表现 |
|---|---|---|
| **写入**（医护→患者） | BCI 向患者脑电发射信号 | 天穹裂开、光倾泻而下、巨影降临、声音直接响在意识里 |
| **读取**（患者→医护） | BCI 解码患者脑电/眼动信号 | 垂直眼动被外界接收为"回应" |

玩家体验到的一切"神秘降临"，都是 BCI 信号在受损意识中的投影。
那些"巨大的影子"是医护团队通过 BCI 投射的存在感——
不是他们本人进入了意识，而是他们的**操作信号**被受损的神经系统
渲染成了可感知的形象。

这也解释了为什么 Eiko 和细胞们看到光时是"敬畏"而非"认识"——
它们从未见过 BCI 信号。对它们来说，这确实是"从外面来的、
超出系统理解能力的力量"。

**BCI 是碳基赛博空间与现实世界的唯一接口。**
后续所有"外部干预"都通过 BCI 通道：
- 医护传达治疗方案 → BCI 写入 → 赛博空间中的"外部提案"
- 患者回应（垂直眼动/脑电） → BCI 读取 → 现实中的"知情同意确认"
- 医疗操作执行 → 生理变化 → 赛博空间中的"系统状态改变"

---

## Phase 5: 同意（Consent）

玩家处于**闭锁状态**。

不能动。不能说话。突触终端界面尚未恢复。
唯一能做的：**垂直眼动**。上看。下看。

这是整个开场最独特的机制——
玩家用垂直眼动来回答。

光中的影子似乎在观察玩家。
然后，那个声音又响起了。

> **声音**：
> "我们看到了你的反应。你还在。很好。"

> **声音**：
> "我们是外面的。我们想帮你——
> 但我们需要你的同意才能进入。这是规矩。"

> **声音**：
> "我们有一个方案。打开被堵住的管道，恢复供血。
> 有风险——但不做的话，剩下的时间不多了。"

光的模式发生了变化。
像是有什么东西在玩家视野里展开——一个非常简单的界面。
不是突触终端，不是文字。是两束光。上面一束，下面一束。

> **声音**：
> "如果你同意——眼睛向上看两次。"
> "如果你拒绝——眼睛向下看，不抬起来。"

（这就是**知情同意**的碳基赛博空间版本。
不是弹窗，不是按钮——是垂直眼动。
BCI 解码患者眼动信号 → "眼睛上视两次"= 同意 → 医护团队获得知情同意 →
执行医疗干预。整个链路在玩家视角中被渲染为"两束光 + 两次上视"。

为什么是垂直眼动而非眨眼？因为闭锁综合征水平眼动丧失（CN VI 损害），
但垂直眼动保留（CN III/IV 在中脑，位于脑桥病变上方）。
这是闭锁综合征患者唯一可靠的自主输出通道。）

**玩家交互**：
- 眼睛上视两次 → 同意
- 眼睛下视不动 → 拒绝（如果玩家真的长时间下视，系统会以为玩家"走了"，
  然后会有一个温柔的"……我明白了"，但光不会消失——最终还是会救。
  这是叙事选择，不是 game over。但第一次玩几乎都会选同意。）

**玩家选择同意（两次上视）**：

短暂的沉默。

然后，那个声音——第一次有了一丝情绪。
像是一个医生，在急诊室里，终于确认了这个被误认为昏迷的患者
确实能通过垂直眼动回应——那种克制住的、轻轻的、释然。

> **声音**：
> "好。"

> **声音**：
> "我们来了。"

---

## Phase 6: 再灌注（Reperfusion）

### 6.1 洪流

天，打开了。

不是比喻——是真的。
缺血区域的主供能管道，被从"外面"打通了。

**洪流。**

温暖的、富含能量的血液——在碳基赛博空间里读作"能量洪流"——
沿着主管道汹涌而入。

灯，一盏接一盏地亮了。
不是慢慢亮——是"轰"的一下，整条走廊、整个穹顶、整片区域，
像被点燃一样，全亮了。

绿色的生物荧光——健康的、充满活力的绿色。

玩家感觉意识调控力回来了。
不是慢慢恢复——是潮水一样涌回来。
视野重新清晰。突触终端重新浮现。能调控了。

周围——细胞们。

它们从各个角落里涌出来。从管道后面、从膜结构的缝隙里、
从神经元的树突之间——它们涌出来，仰头看着光，看着重新亮起的一切。

欢呼声。不是人类的语言——是某种更原始的、生物的、
劫后余生的欢腾。

**然后，洪流带来了新的身影。**

不是这片区域的常驻细胞——是从外面来的。
它们随着再灌注的血流涌入，像援军抵达战场。
它们的气质和 Eiko 明显不同——更大、更规整、动作带着目的性，
像读过了任务简报才来的。

其中一个穿过人群，径直走向 Eiko。

Eiko 看到她。愣住了。

两个人——两个本不该相遇的人——隔着欢腾的细胞群对视。

一个在脑里待了一辈子，从灾难第一分钟就开始独自战斗。
一个从外面来，穿过崩塌的屏障，带着整个外周免疫系统的情报抵达。

> **Eiko**（嘴唇动了动，声音很轻）：
> "……你来了。"

> **来者**（点了点头，声音沉稳）：
> "屏障塌了。我才能进来。"

她转向玩家。她的眼神和 Eiko 不同——
Eiko 的亮是活化的、焦灼的、三天没合眼的那种亮；
她的沉是评估过全局后的、知道最坏情况的、依然选择走进来的那种沉。

她没有自我介绍。她在看那些细胞——
看它们如何转向玩家，如何低语。

低语声，从四面八方传来：

> *"Admin……"*

> *"Admin 同意了……"*

> *"是 Admin 让他们进来的……"*

Eiko 僵住了。她看看那些细胞，又看看玩家。

> **Eiko**（轻声）：
> "它们叫你……Admin？"

她的声音在发抖。不是害怕——是某种更大的东西。

> **Eiko**：
> "我就知道。我第一眼看到你的时候就知道——
> 你不是普通的单元。你是……"

### 6.2 损伤

她没说完。

因为——最亮的那片区域里，有个细胞爆炸了。

不是灯灭了的那种熄灭。是爆炸。
细胞膜破裂，内容物喷出来，荧光四溅。

然后是第二个。第三个。第十个。第一百个。

像鞭炮一样，沿着刚刚恢复供血的主干道，
一个接一个的细胞在破裂。

警报——新的警报。不是缺血的琥珀色，是另一种红色警报。

```
[✕ 紧急] 活性氧爆发 — 氧化应激
[✕ 紧急] 钙超载 — 膜完整性丧失
[✕ 紧急] 炎症级联 — 补体系统激活
```

Eiko 的笑容凝固在脸上。

> **Eiko**（难以置信）：
> "不……"

她冲向最近的一个正在破裂的细胞——但已经晚了。
细胞在她面前碎掉了。

刚到的那位也变了脸色。她快步走向主干道，
蹲下查看一个正在膨胀的细胞——膜上布满了氧化损伤的斑点。

> **来者**（沉声）：
> "再灌注损伤。"
> "它们撑过了缺血——但撑不过血流回来的这一刻。"

远处，更多的细胞在爆炸。
像一场新的、更猛烈的雪崩。

光还在。外面的影子还在。
但它们似乎也没预料到——或者预料到了，但无能为力。
那个声音再次响起，带着一丝沉重。

> **声音**：
> "……我们打通了路。但路的那头，还要靠你们自己。"

> **声音**：
> "保护它们。你有 Admin 调控权——你能做的事，比你想象的多。"

光渐渐退去。影子升回了天穹之上。
膜结构重新闭合。

但留下了。
留下了重新流动的能量管道。
留下了正在爆炸的细胞。
留下了——玩家的 Admin 调控权。

Eiko 转向玩家。
她的脸上还有未干的泪痕，还有惊慌。
但眼底有什么东西——重新燃起来了。

> **Eiko**：
> "你听到了。你有 Admin 调控权。"

> **Eiko**：
> "我救了三天救不了的东西——但你能。"

---

## Phase 7: 出发（Departure）

Eiko 一把拉住玩家（玩家的意识投射体——突触终端界面正在重新浮现——
这一次，不是意识模式的暗淡绿色，是明亮的、完整的、
Admin 级别的生物荧光）。

> **Eiko**：
> "走。还有的救。"

刚到的那位跟上前来。她看了 Eiko 一眼，又看了玩家一眼。
然后开口了——声音不高，但每个字都像经过了精确计算。

> **来者**：
> "Yukio。辅助性T细胞。"
> "外面的屏障塌了，我才能进来。"

她没有解释更多——但 Eiko 的表情微妙地变了一下。
像是想说"你怎么才来"，又咽了回去，变成了"你来了就好"。

玩家跟随 Eiko 和 Yukio，冲向再灌注损伤最严重的区域。
沿途，细胞们让开一条路。
它们看着玩家——不是看一个陌生人，是看一个……
它们以为已经失去的人。

> **Yukio**（边跑边说，语速快但清晰）：
> "这片区域是脑桥供血区——你可以理解为一个街区。
> 一个刚死里逃生、但还在着火的街区。"

> **Eiko**（接话）：
> "你刚才做的事——眼睛上看了两次——那叫'同意'。
> 外面那些人需要你的同意才能进来。但进来之后，剩下的要靠我们自己。"

> **Yukio**：
> "缺血损伤我从外面已经看到了。再灌注损伤——"
> 她看向远处正在爆炸的细胞群，脚步没有停。
> "——才刚开始。"

Eiko 回头看了玩家一眼。
那个在黑暗中奋战了三天的、眼睛发亮的小胶质细胞——
她的赛丽亚式笑容又回来了。带着点倔强，带着点火气。

> **Eiko**：
> "不管你是谁。不管你记不记得自己为什么叫 Admin。"
> "你同意救我们——现在，跟我们一起把这事做完。"

**镜头缓缓拉远**——玩家、Eiko 和 Yukio 三个身影穿过巨大的有机走廊，
冲向远方闪烁的红色警报。走廊两侧是正在恢复、
但也在不断爆炸的细胞结构。
荧光像星星一样一颗颗亮起，又像烟花一样一颗颗熄灭。

更多的黑暗区域等待着。
更多的战场等待着。

**画面渐黑。**

## 角色关系设计笔记

### Eiko 与 Somnambule（玩家）：宋慈与英姑

| 角色 | 参照 | 定位 | 在开场中的体现 |
|---|---|---|---|
| Somnambule（玩家） | 宋慈 | 坐堂提刑——读情报做判断 | 医学天才的直觉：看懂系统、做出诊断、下达"同意" |
| Eiko（小胶质细胞） | 英姑 | 走验现场——冲第一线搜集证据 | 三天独自巡查膜结构、清扫碎片、维持侧支循环 |

宋慈与英姑的关系是"友人之上恋人未满"——他们之间有默契、有信赖、
有一种不需要说出口的深层理解。在 SoMe 中，这种关系表现为：
Eiko 守了三天的战场，玩家到来后本能地理解她在做什么（医学知识=Admin调控权）。
Eiko 提供现场情报（英姑走验现场），玩家提供诊断判断（宋慈坐堂提刑）。
两人配合的默契不是刻意的——是因为他们本就是同一个身体的两面：
一个是意识层面的管理者，一个是细胞层面的执行者。

### Eiko 与 Yukio：生死离别

| 维度 | Eiko（小胶质细胞） | Yukio（辅助性T细胞） |
|---|---|---|
| 来源 | 卵黄囊（胚胎早期迁入脑内） | 胸腺（外周免疫系统） |
| 正常状态 | 脑内常驻 | 被BBB挡在脑外 |
| 相遇条件 | — | BBB破坏（卒中砸碎屏障） |
| 相遇意义 | 第一次见到"外援" | 第一次进入中枢神经系统 |
| 分离条件 | — | 炎症消退后T细胞必须撤出CNS |

她们本不该相遇。BBB（血脑屏障）将中枢神经系统和外周免疫系统隔开，
小胶质细胞在脑内独自巡逻，T细胞在外周待命。
只有灾难——卒中砸碎了 BBB——才让她们在同一个战场上相见。

而恢复之后，T细胞必须撤出中枢神经系统。
她们只能在灾难中相遇，在恢复后分离。

**这个设定不在开场点破**——只是让玩家看到她们对视的那一刻，
感觉到"有什么不对"，然后在后续剧情中慢慢揭示。

**Yukio 的中枢教育履历（地理锚点）**：T 细胞迁移链 = Cervical（Cervical Station 骨髓造船厂，出生）→ Thoracica（奥金谛国 Aukin Empire 的 The Cradle 髓院，中枢耐受教育，外己座 Chair Vasud Stuart 门下；继任者推世者）→ 外周服役（Lumbar/Sacrum，阿珞佩斯）。安斯大为 Lumbar 本土、阿珞佩斯为 Sacrum 本土；奥金谛为 AAA 框架内的禅宗神权中立国，不拥有武装、专司全协约 T 细胞军官的"出厂认证"，力量平衡受《摇篮协约》四重约束（课程共有/无野战军/胸腺退化/各国学员即人质）。详见 `SoMe_Universe_Git/Factions/Aukin_Empire.md`。

## 康复弧线框架（Rehabilitation Arc）

开场只是康复弧线的第一章。玩家的整个游戏进程，就是一场**闭锁综合征的逐步康复**。

### 核心等式

```
调控权恢复 = 神经功能恢复 = 游戏能力解锁
```

玩家在碳基赛博空间中每恢复一项"Admin调控权"，
对应现实中一项神经功能的恢复。
这不是比喻——是 BCI 监测到的真实神经重建在赛博空间中的映射。

### 调控权/功能恢复阶梯

| 阶段 | 赛博空间调控权 | 现实神经功能 | 游戏能力解锁 | 对应脑区/神经 |
|---|---|---|---|---|
| **0. 闭锁** | 仅垂直眼动 | 垂直眼动（CN III/IV保留） | 眼动选择（开场） | 中脑（病变上方，保留） |
| **1. 感知** | 读突触终端 | 视觉/听觉处理恢复 | 查看系统状态 | 枕叶/颞叶 |
| **2. 局部运动** | 单手操作突触终端 | 上肢远端运动 | 单手交互/简单hack | 运动皮层（手区） |
| **3. 移动** | 自由行走 | 躯干/下肢运动 | 开放世界探索 | 运动皮层（腿区）/小脑 |
| **4. 语言** | 语音命令 | 语言功能恢复 | 语音交互/NPC对话 | Broca区/Wernicke区 |
| **5. 记忆** | 海马修复 | 记忆检索恢复 | 解锁个人记忆/身份线索 | 海马体 |
| **6. 执行** | 完整Admin | 前额叶执行功能 | 高级策略/多任务/规划 | 前额叶皮层 |
| **7. 顿悟** | Mode B解锁 | 完整意识恢复 | 跨系统Encounter | 全脑整合 |

### 设计原则

1. **恢复不是线性的**：会有平台期、反复、并发症——对应康复医学的真实规律
2. **每级恢复都有剧情意义**：不是数值升级，是"我又能做XX了"的情感时刻
3. **并发症=新副本**：再灌注损伤、脑水肿、癫痫、感染……每个都是新的游戏内容
4. **海马修复=身份揭示**：当玩家恢复到阶段5，记忆开始回来——这是顿悟的前奏
   （注：开场Phase 0海马在线=记忆完好，但后续并发症可能损伤海马→记忆丢失→修复）
5. **顿悟=Mode A→Mode B转换**：阶段7，玩家完整恢复意识，
   理解了自己的全部经历——然后发现：自己可以反过来使用 BCI，
   进入**其他患者**的意识，成为外来拯救者

### 学术进程——康复即研究

主角的医学天才背景 + BCI 双向通讯能力，使康复过程本身成为前所未有的研究。

团队发现主角能与自身细胞对话后，鼓励主角系统记录体验。
主角的康复弧线同时也是一条学术发表弧线：

| 阶段 | 论文/成果 | 研究内容 |
|---|---|---|
| 1. 感知 | — | 初步观察，尚未成文 |
| 2. 局部运动 | Case Report | "一例闭锁综合征患者的系统级意识体验" |
| 3. 移动 | Short Communication | "缺血半暗带的内部视角：细胞层面的代偿与崩溃" |
| 4. 语言 | Original Research | "意识-细胞双向交互：BCI 介导的新型神经接口" |
| 5. 记忆 | Perspective | "海马损伤与修复的内部体验：记忆重建的细胞视角" |
| 6. 执行 | Review | "从内部观察神经功能恢复：康复医学的新范式" |
| 7. 顿悟 | Landmark Paper | "碳基意识的全栈探索：从患者到研究者" |

**设计原则**：
- 论文不是额外的收集品——它是主线章节的自然产物
- 每完成一个区域的探索+掌握相关医学知识 → 自动触发论文发表剧情
- 论文内容 = 玩家在游戏中实际学到的知识，玩家读完即巩固
- 顿悟后的 Landmark Paper = 游戏通关的学术总结，
  也是 Mode B（帮助其他患者）的理论基础

### 与双模设计的对接

```
Mode A（自系统/漂泊者模式）
  玩家 = 闭锁综合征患者
  目标 = 恢复自己的神经功能（调控权）
  BCI方向 = 医护→患者（被帮助）
  
  ↓ 顿悟（阶段7：完整意识恢复）
  
Mode B（跨系统/Encounter模式）
  玩家 = 康复者/医者
  目标 = 进入其他患者系统，帮助恢复
  BCI方向 = 玩家→其他患者（帮助者）
```

顿悟的本质：你曾经是被 BCI 救助的闭锁患者，
现在你成为手持 BCI 进入他人意识的拯救者。
你经历的每一次"被救"，都成为你"救人"的经验。

### 开场在弧线中的位置

开场（Phase 0-7）= 阶段0→阶段1的过渡。
玩家从"仅垂直眼动"到"突触终端重新浮现"——
这是康复弧线的第一步，也是最戏剧性的一步。

后续游戏内容 = 阶段1到阶段7的完整旅程，
每个阶段对应一个主线章节 + 若干支线（并发症/康复训练/记忆碎片）。

## 附录：一波三折结构分析

| 波次 | 剧情曲线 | 情绪 | 玩家学到 |
|---|---|---|---|
| **第一波** | 自救尝试 → 雪崩失败 | 希望 → 绝望 | 缺血级联反应：为什么脑细胞救不了自己 |
| **第二波** | 误诊昏迷→EEG鉴别→BCI降临→同意→再灌注 | 绝望→敬畏→狂喜 | 闭锁综合征/EEG鉴别/外部医疗干预/知情同意 |
| **第三波** | 再灌注损伤 | 狂喜 → 新危机 | 治疗本身有风险；再灌注损伤的病理机制 |

**核心叙事设计**：玩家以为开场是"一个黑客拯救系统"的故事——
实际上开场就告诉玩家：**你救不了自己。你需要别人来救。
但别人救了你之后，剩下的路还要你自己走。**

而在此之前还有一层更深的恐怖：**你甚至无法告诉别人你需要救**。
你被误认为昏迷。你的意识在尖叫，但没有人听得见——
直到有人做了脑电图，有人检查了你的垂直眼动。

这是 SoMe 的核心命题之一：
医学不是万能的，但没有医学是万万不能的。
而最终决定一个人能不能活下来的——
是治疗，也是身体自己的战斗。

## 附录：竞品开场对比

| 游戏 | 开场核心动作 | 情感基调 | 转折次数 |
|---|---|---|---|
| 原神 | 与未知神明战斗 → 失去血亲 | 悲伤 + 复仇驱动 | 1次（从日常到灾难） |
| 鸣潮 | 战斗中醒来 → 遇到同伴 | 困惑 + 探索驱动 | 1次（从孤独到有伴） |
| **SoMe** | **被误诊昏迷→EEG鉴别→自救→失败→获救→新灾难** | **恐惧→绝望→敬畏→狂喜→新危机** | **4次（四波）** |

SoMe 开场的独特之处：
1. **闭锁体验**：玩家亲身经历闭锁综合征——意识清醒但全身瘫痪，被误认为昏迷
2. **意识级操控降级**：玩家的意识调控能力本身就是剧情的一部分
3. **误诊→确诊→救治**：完整的临床诊断链条嵌入叙事
4. **五分钟内四起四落**：情绪密度远高于同类游戏
5. **第一分钟就参与**：不是看十分钟动画，是一直在做事情
6. **三重暗度陈仓**：一门课变三门课（闭锁+缺血/知情同意/再灌注）
7. **Eiko 立住了**：奋战三天的小胶质细胞引导员，有血有肉有情绪
8. **双角色递进登场**：Eiko（秧秧位/前线/常驻）先行建立情感连接，
   Yukio（今汐位/外援/战略）在再灌注时随血流抵达——
   两种免疫细胞的相遇本身就是一个生物学故事
