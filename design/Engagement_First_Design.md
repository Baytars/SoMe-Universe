## 1. 核心原则：上头优先

> **先让人上头，把时间和注意力投入进去，再让人学点东西进一步上头。**

这是SoMe"暗度陈仓"策略在产品节奏层面的落地：

```
传统教育游戏：    先教育 → 顺便好玩 → 没人来
SoMe的做法：      先上头 → 投入时间 → 知识渗透 → 进一步上头
```

**设计铁律：**
- MVP阶段不需要完整玩法，但**必须有上头钩子**
- 上头钩子优先于教育内容部署
- 知识渗透是上头的副产品，不是上头的前提条件
- 再简陋也要让人上头——上头的简陋 > 无聊的精致

## 2. 上头机制心理学总览

所有上头机制归为三条底层驱动线：

### 2.1 多巴胺线（期待/变率强化）

| 机制 | 心理学原理 | SoMe对应 |
|---|---|---|
| 抽卡出金期待 | 变率强化（Variable Ratio Schedule） | FACS抽卡——物理意义的抽卡 |
| PVP赢一把输三把 | 心流区间 + 近胜效应 | SRPG缺血-再灌注相位制造的"差点赢了" |
| 限时FOMO | 损失厌恶 | 限定细胞池/限时活动分选 |
| "再来一把" | 零摩擦重开 | Roguelike式突触修剪挑战关 |

**核心洞察**：不是"得到"让人上头，是"可能得到"让人上头。50%胜率附近最上瘾。情绪振幅比情绪正负值更上头——悲喜交加 > 纯赢。

### 2.2 情感/社交线

| 机制 | 心理学原理 | SoMe对应 |
|---|---|---|
| 角色立绘/性格/故事 | 情感依恋 + 准社会关系 | Eiko的72小时孤守 + 首席立绘师模式 |
| 社交绑定 | 社交关系锁留 | （待设计）联机分选/细胞交换 |
| 收集图鉴 | 完成欲 + 收集癖 | 标本柜——细胞/病原体图鉴 |
| 社交分享图 | 社交货币 + 零成本获客 | 战绩/抽卡/图鉴分享图 |

**核心洞察**：你不是在玩角色，你是在"养"一个人。戒游戏难不是因为游戏好玩了，是因为朋友还在、角色还在等你。

### 2.3 掌控感/完成欲线

| 机制 | 心理学原理 | SoMe对应 |
|---|---|---|
| 成长可视化 | 能力感（Competence） | 数值成长 + 技能树点亮 |
| 红点点强迫症 | 蔡格尼克效应 | 图鉴未收录提示/任务提醒 |
| 放置帝国感 | 掌控持续运行的系统 | 家园系统——挂机时细胞在培养箱运转 |
| 版本meta变迁 | 智力破解快感 | 代谢系统理解→"破解"最优build |

**核心洞察**：看着进度条在动就爽。"我的系统在运转"的满足感来自掌控一个持续运行的系统。

### 2.4 隐形上头引擎：音效

| 场景 | 音效 | 作用 |
|---|---|---|
| FACS出稀有细胞 | 清脆"叮"+ 心跳加速弦乐 | 最短路径的情绪触发器 |
| 图鉴收录完成 | 柔和"咔哒" + 短旋律 | 完成感的声音锚定 |
| M1极化切换 | 低沉"嗡"开关声 | 紧张感建立 |
| 分享图生成 | 轻快"唰" + 叮咚 | 分享行为的正向反馈 |

> 音效不是装饰——声音是最短路径的情绪触发器，能让平庸动作产生生理性爽感。

## 3. 社交分享图设计

### 3.1 设计原则

好分享图的共性：**自带"炫耀"或"搞笑"属性 + 自带"好奇心钩子"**

| 分享类型 | 机制 | 情绪 | SoMe示例 |
|---|---|---|---|
| 炫耀型 | 晒运/晒稀有 | "我抽到了！" | FACS分选到0.03%稀有细胞 |
| 战绩型 | 晒实力 | "看我多强" | SRPG单回合伤害/通关评价 |
| 搞笑型 | 社交货币 | "哈哈哈哈" | M1误伤友军把自家神经元全清了 |
| 误解型 | 好奇心钩子 | "这是什么？" | 碳基术语让圈外人一头雾水但觉得好厉害 |

### 3.2 SoMe的核心优势：碳基术语=好奇心钩子

别的游戏分享图需要靠画风吸引注意。SoMe的碳基术语本身就是钩子——

不认识的人看到"突触修剪完成率98.7%""氧化爆发伤害12,840""误伤友军-3,420"：

**完全看不懂但觉得好厉害。**

这就是钩子。他们会问"这是什么游戏？"，而SoMe的碳基术语让他们即使搜到了也"看不太懂但更好奇了"。

> *暗度陈仓在社交传播层面的终极形态：用术语壁垒制造信息差，用信息差驱动好奇心，用好奇心驱动下载。*

### 3.4 分享图技术实现

| 维度 | 方案 |
|---|---|
| 渲染 | Canvas 2D API（ct.js原生支持） |
| 立绘 | 预渲染为静态图层叠加 |

## 4. MVP上头闭环

### 4.1 最小上头飞轮

```
FACS抽卡（多巴胺钩子）
    ↓
抽到新细胞 → 图鉴收录（完成欲钩子）
    ↓
图鉴条目解锁角色故事碎片（情感钩子）
    ↓
截图分享朋友圈（社交钩子）
    ↓
朋友来问"什么游戏" → 新玩家进入
    ↓
新玩家抽卡 → 循环重启
```

**这个闭环里没有完整SRPG战斗、没有开放世界、没有3D实验室——但已经有四个上头钩子在转了。**

### 4.2 开发优先级

| 优先级 | 功能 | 上头钩子 | 开发复杂度 | 技术栈 |
|---|---|---|---|---|
| **P0** | FACS抽卡 | 变率强化（多巴胺） | 低——概率+动画+音效 | ct.js + Canvas |
| **P0** | 分享图生成 | 社交传播 | 低——Canvas渲染+模板 | ct.js + Web Share API |
| **P1** | 图鉴/标本柜 | 收集癖+完成欲 | 中——数据表+UI | ct.js + JSON数据 |
| **P1** | 角色故事碎片 | 情感依恋 | 低——文本+立绘 | ct.js + Ink片段 |
| **P2** | 简化SRPG战斗 | 心流+情绪振幅 | 高——完整战斗系统 | ct.js + SRPG框架 |
| **P3** | 家园系统3D | 放置帝国感 | 很高——3D渲染+交互 | Three.js |
| **P3** | 解剖开放世界 | 探索+发现 | 很高——大地图+物理 | Three.js |

### 4.3 P0详细规格

#### P0-1: FACS抽卡

**核心循环**：
1. 玩家拥有N次分选机会（每日回复+任务获取+代币购买）
2. 点击"开始分选"→ 动画：细胞悬液流过激光检测通道
3. 细胞逐个闪过（概率展示）→ 突然某个细胞标记亮起（稀有度颜色）
4. 黑屏 → 立绘展现 → 角色台词 → 稀有度确认
5. 新收录→图鉴解锁动画；已收录→转化为代谢资源

**概率框架**：
| 稀有度 | 概率 | 对应细胞类型 | 碳基术语 |
|---|---|---|---|
| SSR | 0.1% | 记忆T细胞/神经干细胞 | "百年记忆载体" |
| SR | 5% | 激活型T细胞/NK细胞 | "精锐效应单位" |
| R | 30% | 常规巨噬细胞/B细胞 | "标准响应单位" |
| N | 64.9% | 普通上皮细胞/红细胞 | "基础维持单位" |

**保底机制**：50次分选必出SR+，100次必出SSR（与主流抽卡游戏一致）

**关键音效**：
- 分选通道运行：低频持续音
- 细胞逐个闪过：短促"嘀嘀嘀"
- 稀有标记亮起：突然静音0.5秒 → 心跳声
- SSR出金：清脆"叮"+ 弦乐渐强
- 立绘展现："唰"的展开声

#### P0-2: 分享图生成

**触发点**：
- 抽到SSR/SR时自动弹出"分享"按钮
- 图鉴收录里程碑（每50/100/250个）
- 战斗评级S时（P2上线后）

**实现**：
- Canvas 2D绘制 → toDataURL → 1080×1920 PNG
- 模板A/B/C三种（见§3.3）
- 移动端：Web Share API直接调起系统分享
- 桌面端：下载图片+复制链接

**设计要求**：
- 分享图上必须有SoMe logo + 下载入口
- 立绘必须清晰可辨（吸引视觉）
- 碳基术语必须显眼（制造好奇心钩子）
- 适配朋友圈/小红书/Twitter竖版比例

### 4.4 P1详细规格

#### P1-1: 图鉴/标本柜

- 每个收录条目：立绘 + 碳基名称 + 玩家透镜名称 + 简短描述
- 未收录条目显示为剪影 + "???"
- 收录进度条（总进度+分类进度）
- 红点点提醒：有新可收录条目时
- 首次收录弹出庆祝动画

#### P1-2: 角色故事碎片

- 每个SSR/SR细胞有3-5段故事碎片
- 通过图鉴收录/重复获取/特定条件解锁
- 用Ink脚本实现简单分支对话
- 碎片拼合成完整角色弧线

## 6. "进一步上头"的知识渗透路径

上头之后，知识怎么渗透而不打断上头：

| 阶段 | 玩家行为 | 知识渗透方式 | 玩家感受 |
|---|---|---|---|
| 抽卡 | 分选细胞 | 碳基名称+稀有度对应真实细胞频率 | "这个细胞好稀有" |
| 图鉴 | 浏览条目 | 每条目简短碳基描述（真实生物学） | "原来这种细胞是干这个的" |
| 故事 | 读角色碎片 | 角色故事含医学情境（如Eiko的72小时孤守=脑缺血后小胶质细胞响应时间线） | "这角色好惨但好酷" |
| 战斗(P2) | SRPG对战 | 目标类型修饰表让玩家自然发现"不同敌人要用不同攻击" | "大怪不能用吞噬？那用什么？" |
| 深度(P3) | 家园/实验室 | 真实数据库驱动的数值让玩家接触真实生物参数 | "这个细菌的肽聚糖真的比那个厚？" |

> **关键：每个阶段的知识渗透都不是"教学"，是"发现"。玩家自己发现的知识会记住，被灌输的知识会忘记。**

## 7. 度量指标

MVP阶段的北极星指标：

| 指标 | 目标 | 含义 |
|---|---|---|
| 次日留存 | >40% | 上头钩子是否有效 |
| 分享率 | >5% | 社交分享图是否吸引人 |
| 自然新增占比 | >30% | 分享图带来的零成本获客是否work |
| 图鉴完成度中位数 | >20% | 收集钩子是否驱动持续游玩 |
| 单次会话时长 | >5min | 短循环是否足够上头 |
